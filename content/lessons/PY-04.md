## Why this matters
Lists hold the collections that programs work with every day: movie titles, order lines, search results, and rows read from a file. A list is mutable, so some operations change it in place while others quietly build a new list. Knowing which is which prevents the most common list bugs.

## What you will build
Small, standalone Python scripts that create lists, read parts of them, add and remove items, sort and combine them, and convert between strings and lists. You finish with a movie watchlist program that prints its state after eleven tasks.

## Before you start
Use Python 3.10 or newer and create each named file in a practice folder. Every example is independent. Run each file with `python3 filename.py` on macOS/Linux or `py -3 filename.py` in Windows PowerShell.

A list is an ordered, changeable collection written in square brackets. It keeps duplicates and can hold items of different types. Indexing and slicing work as they did for strings in PY-03, and in-place changes build on the mutability you met in PY-01.

## Step 1: Create a list
A list can be written as a literal, built with the `list()` constructor, or produced by `str.split()`. Because lists are ordered, mutable, and allow duplicates, you can replace an item in place and store the same value twice.

```python title="list_basics.py" file
movies = ["Inception", "Avatar", "Gladiator"]
empty = []
empty_too = list()
letters = list("abc")
words = "Matrix Alien Shrek".split()
mixed = [1, "two", 3.0, True]

print(movies)
print(empty, empty_too, empty == empty_too)
print(letters, words)
print(mixed, type(mixed).__name__)

movies[0] = "Memento"
print(movies)
print(["Jaws", "Jaws"].count("Jaws"))
```

```bash title="Terminal" verify="run"
python3 list_basics.py
```

```text title="Expected output"
['Inception', 'Avatar', 'Gladiator']
[] [] True
['a', 'b', 'c'] ['Matrix', 'Alien', 'Shrek']
[1, 'two', 3.0, True] list
['Memento', 'Avatar', 'Gladiator']
2
```

`list("abc")` splits any iterable into items, so a string becomes one item per character. `[]` and `list()` both make an empty list.

## Step 2: Index and slice a list
Square brackets pick items by position. Negative numbers count from the end, and a slice returns a new list: the start is included, the stop is excluded, and a third number sets the step.

```python title="list_index_slice.py" file
m = ["Titanic", "Rocky", "Jaws", "Inception", "Gladiator"]

print(m[0], m[-1])
print(m[1:3])
print(m[:2])
print(m[2:])
print(m[::2])
print(m[::-1])
print(m)
print(m[1:99])
print(m[3:1])
```

```bash title="Terminal" verify="run"
python3 list_index_slice.py
```

```text title="Expected output"
Titanic Gladiator
['Rocky', 'Jaws']
['Titanic', 'Rocky']
['Jaws', 'Inception', 'Gladiator']
['Titanic', 'Jaws', 'Gladiator']
['Gladiator', 'Inception', 'Jaws', 'Rocky', 'Titanic']
['Titanic', 'Rocky', 'Jaws', 'Inception', 'Gladiator']
['Rocky', 'Jaws', 'Inception', 'Gladiator']
[]
```

`m[::-1]` is a reversed copy, and `m` itself is unchanged. A single index outside the list raises `IndexError`, but a slice never does: it clips to the list or returns an empty list.

## Step 3: Look things up
Built-in functions and a few methods answer questions about a list without changing it. `in` tests membership, `index()` finds the first match, and `count()` counts matches. `index()` raises `ValueError` when the value is missing.

```python title="list_lookups.py" file
m = ["Titanic", "Rocky", "Jaws", "Inception", "Gladiator"]

print(len(m))
print("Jaws" in m, "Zorro" in m)
print(m.index("Jaws"), m.count("Jaws"))
print(min(m), max(m))

try:
    m.index("Zorro")
except ValueError as error:
    print("ValueError:", error)

try:
    m[5]
except IndexError as error:
    print("IndexError:", error)
```

```bash title="Terminal" verify="run"
python3 list_lookups.py
```

```text title="Expected output"
5
True False
2 1
Gladiator Titanic
ValueError: 'Zorro' is not in list
IndexError: list index out of range
```

`min()` and `max()` compare strings alphabetically here. Test with `in` first when a value might be missing, and catch the exception only when failing is a normal outcome.

## Step 4: Add items
`append()` adds one item to the end, `insert(i, x)` puts `x` before index `i`, and `extend()` adds every item of another list or any iterable. All three change the list in place and return `None`.

```python title="list_add.py" file
lst = ["B", "C"]

print(lst.append("D"))
print(lst)

lst.insert(0, "A")
print(lst)

lst.insert(99, "E")
print(lst)

lst.extend(["Z", "Y"])
print(lst)

lst.extend("xy")
print(lst)
```

```bash title="Terminal" verify="run"
python3 list_add.py
```

```text title="Expected output"
None
['B', 'C', 'D']
['A', 'B', 'C', 'D']
['A', 'B', 'C', 'D', 'E']
['A', 'B', 'C', 'D', 'E', 'Z', 'Y']
['A', 'B', 'C', 'D', 'E', 'Z', 'Y', 'x', 'y']
```

An `insert()` index past the end simply adds at the end. `extend()` with a string adds one item per character, and an argument that is not iterable raises `TypeError`.

## Step 5: Remove items
`remove(x)` deletes the first item equal to `x` and returns `None`. `pop()` removes the last item, or the item at an index, and is the only core method that hands back a value. Check first when the value or the list might be missing.

```python title="list_remove.py" file
lst = ["A", "B", "C", "B", "D"]

print(lst.remove("B"))
print(lst)

last = lst.pop()
print(last, lst)

first = lst.pop(0)
print(first, lst)

if "Q" in lst:
    lst.remove("Q")
else:
    print("Q is not in the list")

empty = []
if empty:
    empty.pop()
else:
    print("nothing to pop")
```

```bash title="Terminal" verify="run"
python3 list_remove.py
```

```text title="Expected output"
None
['A', 'C', 'B', 'D']
D ['A', 'C', 'B']
A ['C', 'B']
Q is not in the list
nothing to pop
```

Only the first `"B"` was removed. `remove()` on a missing value raises `ValueError`, and `pop()` on an empty list or a bad index raises `IndexError`. An empty list is falsy, so `if empty:` is a tidy guard.

## Step 6: Sort and reverse
`sort()` orders the list in place, ascending by default, and `reverse()` flips it in place. Both return `None`. `sorted(lst)` returns a new sorted list and leaves the original alone. Use `key=` to change how items are compared.

```python title="list_order.py" file
lst = ["B", "D", "A", "C"]

print(lst.sort())
print(lst)

lst.reverse()
print(lst)

scores = [20, 5, 100]
scores.sort(reverse=True)
print(scores)

original = ["C", "A", "B"]
ordered = sorted(original)
print(original, ordered)

names = ["apple", "Banana", "cherry"]
names.sort()
print(names)
names.sort(key=str.lower)
print(names)

try:
    [3, "two", 1].sort()
except TypeError as error:
    print("TypeError:", error)
```

```bash title="Terminal" verify="run"
python3 list_order.py
```

```text title="Expected output"
None
['A', 'B', 'C', 'D']
['D', 'C', 'B', 'A']
[100, 20, 5]
['C', 'A', 'B'] ['A', 'B', 'C']
['Banana', 'apple', 'cherry']
['apple', 'Banana', 'cherry']
TypeError: '<' not supported between instances of 'str' and 'int'
```

Uppercase letters sort before lowercase ones, so use `key=str.lower` for a case-insensitive order. Items that cannot be compared, such as numbers mixed with strings, raise `TypeError`.

## Step 7: Join and repeat lists with + and *
`+` joins two lists and `*` repeats a list. Unlike the methods above, both build a new list and leave the originals untouched, so the result must be stored in a variable or it is lost.

```python title="list_operators.py" file
a = ["Titanic", "Rocky"]
b = ["Frozen", "Coco"]

print(a + b)
print(a * 2)
print(a, b)

a + b
print(a)

combined = a + b
print(combined)
print(combined is a)
```

```bash title="Terminal" verify="run"
python3 list_operators.py
```

```text title="Expected output"
['Titanic', 'Rocky', 'Frozen', 'Coco']
['Titanic', 'Rocky', 'Titanic', 'Rocky']
['Titanic', 'Rocky'] ['Frozen', 'Coco']
['Titanic', 'Rocky']
['Titanic', 'Rocky', 'Frozen', 'Coco']
False
```

The bare `a + b` line computes a list and throws it away, so `a` is unchanged. Use `extend()` when you want to grow the existing list instead of creating a new one.

## Step 8: Convert between strings and lists
`split()` turns a string into a list. With no argument it splits on any run of whitespace, and with a separator it splits wherever that text appears. `" ".join(lst)` is the reverse: it glues string items together with the separator.

```python title="list_strings.py" file
print("Matrix Alien Shrek".split())
print("Matrix, Alien, Shrek".split(", "))
print(" Matrix  Alien Shrek ".split())
print("a,b,,c".split(","))

movies = ["Matrix", "Alien", "Shrek"]
print(" ".join(movies))
print(", ".join(movies))
print(" ".join(movies).split() == movies)

try:
    " ".join(["Matrix", 7])
except TypeError as error:
    print("TypeError:", error)
```

```bash title="Terminal" verify="run"
python3 list_strings.py
```

```text title="Expected output"
['Matrix', 'Alien', 'Shrek']
['Matrix', 'Alien', 'Shrek']
['Matrix', 'Alien', 'Shrek']
['a', 'b', '', 'c']
Matrix Alien Shrek
Matrix, Alien, Shrek
True
TypeError: sequence item 1: expected str instance, int found
```

Splitting on whitespace ignores extra spaces, but an explicit separator keeps empty items. `join()` is a string method and needs every item to be a string; convert numbers with `str()` first.

## Step 9: Copy a list instead of aliasing it
`b = a` does not copy anything: both names point to the same list, so a change through one name shows up through the other. `a.copy()` makes a new list with the same items. The copy is shallow, so nested lists are still shared. `clear()` empties a list in place.

```python title="list_copies.py" file
a = ["Jaws", "Rocky"]
b = a
c = a.copy()

b.append("Coco")
print(a, b, c)
print(a is b, a is c)

nested = [["Jaws"], ["Rocky"]]
shallow = nested.copy()
shallow[0].append("Alien")
print(nested)

c.clear()
print(c, len(c))
```

```bash title="Terminal" verify="run"
python3 list_copies.py
```

```text title="Expected output"
['Jaws', 'Rocky', 'Coco'] ['Jaws', 'Rocky', 'Coco'] ['Jaws', 'Rocky']
True False
[['Jaws', 'Alien'], ['Rocky']]
[] 0
```

This ties back to PY-01: `a is b` is true because both names refer to one object. Use `copy.deepcopy()` from the standard library when nested lists must be independent as well.

## Step 10: Avoid the common list mistakes
Most list bugs come from a few habits. This script shows three of them next to their fixes: `append()` versus `extend()`, assigning the result of `sort()`, and removing only the first copy of a repeated value.

```python title="list_mistakes.py" file
lst = ["Titanic", "Jaws"]
lst.append(["Rocky", "Coco"])
print(lst)

lst = ["Titanic", "Jaws"]
lst.extend(["Rocky", "Coco"])
print(lst)

scores = [3, 1, 2]
scores = scores.sort()
print(scores)

scores = sorted([3, 1, 2])
print(scores)

movies = ["Jaws", "Rocky", "Jaws"]
movies.remove("Jaws")
print(movies)

movies = ["Jaws", "Rocky", "Jaws"]
movies = [m for m in movies if m != "Jaws"]
print(movies)
```

```bash title="Terminal" verify="run"
python3 list_mistakes.py
```

```text title="Expected output"
['Titanic', 'Jaws', ['Rocky', 'Coco']]
['Titanic', 'Jaws', 'Rocky', 'Coco']
None
[1, 2, 3]
['Rocky', 'Jaws']
['Rocky']
```

`append()` adds its argument as one nested item, while `extend()` adds each item. `scores = scores.sort()` replaces the list with `None`. The earlier steps cover the other fixes: check before `remove()` or `pop()`, copy instead of aliasing, and sort with `key=str.lower`.

## How it works
A list is an ordered sequence of references to objects. Indexing and slicing read from it; methods such as `append()`, `insert()`, `remove()`, `pop()`, `extend()`, `sort()`, and `reverse()` change the same list object, which is why they return `None` (except `pop()`, which returns the removed item). Operators such as `+` and `*`, slicing, `sorted()`, and `copy()` create a new list instead.

Because a list is mutable, assigning it to a second name creates an alias rather than a copy. The common exceptions follow the operation: `IndexError` for a bad index or an empty `pop()`, `ValueError` for `remove()` or `index()` on a missing value, and `TypeError` for sorting or joining items of the wrong type.

## Common errors
### `lst = lst.sort()` leaves `None` in the variable
`sort()` changes the list in place and returns `None`. Call `lst.sort()` on its own line, or use `lst = sorted(lst)` when you want a new sorted list.

### `ValueError: list.remove(x): x not in list`
`remove()` raises this error when the value is absent. Check with `if value in lst:` first, or catch `ValueError` when a missing value is expected.

### `IndexError: pop from empty list`
`pop()` has nothing to remove from an empty list, and `lst[i]` raises `IndexError: list index out of range` for a bad index. Check `if lst:` before popping and keep indexes within `-len(lst)` to `len(lst) - 1`.

### A whole list appears as one nested item
`append(["Jaws", "Rocky"])` adds a single nested list. Use `extend(["Jaws", "Rocky"])` to add each item.

### Changing one list changes another
`b = a` makes two names for one list. Use `b = a.copy()` for an independent top-level copy.

### `TypeError: '<' not supported between instances of 'str' and 'int'`
`sort()` cannot compare numbers with strings. Convert the items to one type, or pass a `key=` function that returns comparable values.

## Recap
- Lists are ordered and mutable; indexing, slicing, `+`, `*`, `sorted()`, and `copy()` leave the original alone.
- `append()`, `insert()`, `remove()`, `extend()`, `sort()`, and `reverse()` change the list in place and return `None`, while `pop()` returns the removed item.
- `split()` and `join()` convert between strings and lists, and `b = a` is an alias, not a copy.

## Final practice: Movie Watchlist
The cheat sheet ends with one program that covers eleven list tasks. Create `movie_watchlist.py`; it prints the list after each operation so you can watch the list change.

```python title="movie_watchlist.py" file
# Movie Watchlist - all 11 tasks in one program
# 1. Create the list
my_watchlist = ["Inception", "Avatar", "Gladiator"]
print("1. Initial watchlist:", my_watchlist)

# 2. append() - add to the end
my_watchlist.append("Interstellar")
print("2. After append:", my_watchlist)

# 3. insert() - add at the beginning (index 0)
my_watchlist.insert(0, "Titanic")
print("3. After insert:", my_watchlist)

# 4. remove() - delete the first matching value
my_watchlist.remove("Avatar")
print("4. After remove:", my_watchlist)

# 5. pop() - remove the last item and keep it
removed_movie = my_watchlist.pop()
print("5. Removed movie:", removed_movie)

# 6. extend() - add several items at once
my_watchlist.extend(["Jaws", "Rocky"])
print("6. After extend:", my_watchlist)

# 7. sort() - alphabetical order (in place)
my_watchlist.sort()
print("7. After sort:", my_watchlist)

# 8. reverse() - flip the order (in place)
my_watchlist.reverse()
print("8. After reverse:", my_watchlist)

# 9. + operator - concatenate into a NEW list
combined_watchlist = my_watchlist + ["Frozen", "Coco"]
print("9. After concatenation:", combined_watchlist)

# 10. * operator - repeat the list twice into a NEW list
duplicated_watchlist = my_watchlist * 2
print("10. After repetition:", duplicated_watchlist)

# 11. split() - convert a string into a list
movie_text = "Matrix Alien Shrek"
movie_list = movie_text.split()
print("11. Converted list:", movie_list)
```
