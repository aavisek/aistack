## Why this matters
Sets answer questions that lists answer slowly or awkwardly: which values are distinct, is this item present, what do two groups have in common, and what is in one group only. Membership tests are a hash lookup rather than a scan, and set algebra replaces nested loops with a single operator. The frozenset adds an immutable, hashable version you can use as a dictionary key or keep safe from changes.

## What you will build
Small, standalone Python scripts that create sets, add and remove items, combine and compare sets with operators and methods, remove duplicates, and use frozensets. You finish with a student course enrollments program that compares two course groups and protects a list of mandatory courses.

## Before you start
Use Python 3.10 or newer and create each named file in a practice folder. Every example is independent. Run each file with `python3 filename.py` on macOS/Linux or `py -3 filename.py` in Windows PowerShell.

A set is an unordered collection of unique, hashable items: no indexing, no duplicates, and a fast `in` test. A `set` can change after it is created, a `frozenset` cannot. Sets build on the lists from PY-04 and the object identity ideas from PY-01. Because set order can differ between runs for strings, the scripts print sets through `sorted()` so your output matches the lesson.

## Step 1: Create a set
A set can be written with braces, built from any iterable with `set()`, or produced by a set comprehension. Duplicates vanish. `{}` is an empty dictionary, so the only way to make an empty set is `set()`. The scripts print `sorted(...)` because a set has no order to rely on.

```python title="set_create.py" file
a = {1, 2, 3, 3, 2}
print(sorted(a), type(a).__name__)

from_list = set([4, 5, 5, 6])
print(sorted(from_list))

print(sorted(set("mississippi")))

empty = set()
print(empty, type(empty).__name__)
print(type({}).__name__)

squares = {n * n for n in range(6)}
print(sorted(squares), len(squares))
```


```text title="Expected output"
['i', 'm', 'p', 's']
```

`set("mississippi")` splits the string into characters and keeps one of each. `sorted()` returns a list, which is why the values print in square brackets.

## Step 2: Know which items a set can hold
Set elements must be hashable, which in practice means immutable: numbers, strings, tuples of hashable items, and frozensets. Lists, dicts, and sets raise `TypeError`. Values that are equal and have equal hashes count as one item, so `1`, `1.0`, and `True` collapse into whichever the set saw first. `set("abc")` splits a string, while `{"abc"}` keeps it whole.

```python title="set_hashable.py" file
mixed = {1, "two", (3, 4), 5.0}
print(len(mixed), (3, 4) in mixed, "two" in mixed)

try:
    {[1, 2], 3}
except TypeError as error:
    print("TypeError:", error)

try:
    {{1, 2}, {3}}
except TypeError as error:
    print("TypeError:", error)

print(sorted(set("abc")))
print({"abc"} == {"abc"}, len({"abc"}))

print(len({1, 1.0, True}))
print({1, 1.0, True})
print(len({True, 1, 1.0}), {True, 1, 1.0})
```

## Step 3: Add, remove, and update
`add(x)` adds one item and does nothing if it is already there. `update(...)` adds every item from one or more iterables. `remove(x)` raises `KeyError` when `x` is missing, `discard(x)` stays silent, and `pop()` removes and returns an arbitrary item. `clear()` empties the set, and `copy()` or `set(s)` makes a shallow copy. The changing methods return `None`, except `pop()`, which returns the removed item.

```python title="set_update.py" file
s = {10, 20, 30}
print(s.add(40))
s.add(10)
print(sorted(s))

s.update([50, 60], {70})
print(sorted(s))

s.remove(20)
s.discard(999)
print(sorted(s))

try:
    s.remove(999)
except KeyError as error:
    print("KeyError:", error)

removed = s.pop()
print(removed in {10, 30, 40, 50, 60, 70}, len(s))

try:
    set().pop()
except KeyError as error:
    print("KeyError:", error)

copy = s.copy()
print(copy == s, copy is s, set(s) == s)
print(len(s), 10 in copy)
s.clear()
print(s, len(copy))
```

## Step 4: Combine sets with set algebra
Four operations cover most needs. Union `|` keeps items in either set, intersection `&` keeps items in both, difference `-` keeps items in the left set only, and symmetric difference `^` keeps items in exactly one set. Each operator has a named method that gives the same result, and none of them change the originals.

```python title="set_algebra.py" file
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(sorted(a | b))
print(sorted(a & b))
print(sorted(a - b))
print(sorted(b - a))
print(sorted(a ^ b))

print(a.union(b) == a | b)
print(a.intersection(b) == a & b)
print(a.difference(b) == a - b)
print(a.symmetric_difference(b) == a ^ b)
print(a, b)
```

```bash title="Terminal" verify="run"
python3 set_algebra.py
```


Difference is the only one of the four where order matters: `a - b` and `b - a` give different results. After all the operations, `a` and `b` still hold their original items.

## Step 5: Compare sets and update them in place
`<=` and `issubset()` test whether every item of one set is in another, and `<` means a proper subset. `>=`, `>`, and `issuperset()` go the other way, and `isdisjoint()` tests for no shared items. The in-place forms `|=`, `&=`, `-=`, and `^=` change the left set. Operators need a set on both sides, but the named methods accept any iterable.

```python title="set_relations.py" file
a = {1, 2, 3, 4}

print({3, 4} <= a, {3, 4}.issubset(a))
print({1, 2, 3, 4} <= a, {1, 2, 3, 4} < a)
print(a >= {1, 2}, a.issuperset({1, 2}), a > a)
print({1, 2}.isdisjoint({3, 4}), {1, 2}.isdisjoint({2, 3}))

x = {1, 2, 3, 4}
x |= {5}
print(sorted(x))
x &= {2, 3, 5, 9}
print(sorted(x))
x -= {5}
print(sorted(x))
x ^= {3, 7}
print(sorted(x))

y = {1, 2, 3}
y.update([7])
y.intersection_update([1, 2, 7, 8])
y.difference_update([8, 7])
y.symmetric_difference_update([2, 9])
print(sorted(y))

print(sorted(a.intersection([2, 3, 9])))
print(sorted(a.union([7, 8])))

try:
    a | [9]
except TypeError as error:
    print("TypeError:", error)
```

## Step 6: Use sets for everyday tasks
Sets shine at removing duplicates and counting distinct values. `set(nums)` removes duplicates but loses the order, while `list(dict.fromkeys(nums))` removes them and keeps the first-seen order. Because a set has no order, call `sorted()` to get a list. `min()`, `max()`, `sum()`, `len()`, and `any()` all accept a set, and a comprehension can filter one.

```python title="set_patterns.py" file
nums = [3, 1, 3, 2, 1]
print(sorted(set(nums)))
print(list(dict.fromkeys(nums)))
print(len(set(nums)))

print(sorted({5, 2, 9}, reverse=True))
print(min({5, 2, 9}), max({5, 2, 9}), sum({5, 2, 9}))
print(any(x > 8 for x in {5, 2, 9}))
print(sorted({x for x in range(10) if x % 3 == 0}))

words = ["apple", "pear", "apple", "fig", "pear"]
print(sorted(set(words)))
print(len(words) != len(set(words)))
```

## Step 7: Freeze a set with frozenset
A frozenset supports every read-only set operation but none of the changing ones, so `add`, `remove`, `update`, `pop`, and `clear` do not exist and raise `AttributeError`. There is no literal; build it with `frozenset(iterable)`. The result of `x | y` has the type of the left operand, and a frozenset equals a set with the same items.

```python title="frozen_basics.py" file
fs = frozenset([1, 2, 3, 2])
print(fs)
print(sorted(fs))
print(frozenset())

try:
    fs.add(4)
except AttributeError as error:
    print("AttributeError:", error)

try:
    fs.remove(1)
except AttributeError as error:
    print("AttributeError:", error)

print(sorted(fs & {2, 3, 9}), sorted(fs - {1}))
print({1, 2} <= fs, fs.isdisjoint({7}), 2 in fs, len(fs))

print(type(fs | {5}).__name__, sorted(fs | {5}))
print(type({5} | fs).__name__, sorted({5} | fs))
print(frozenset({1, 2}) == {1, 2})
print(hash(frozenset({1, 2})) == hash(frozenset({2, 1})))
```

## Step 8: Use a frozenset as a key or an element
Because a frozenset is immutable it is hashable, so it can be a dictionary key or an item inside another set. A plain set cannot, because it could change after being stored. Item order inside the frozenset does not matter when looking up a key, and copying a set with `frozenset()` freezes a snapshot that later changes do not touch.

```python title="frozen_keys.py" file
roles = {
    frozenset({"read"}): "viewer",
    frozenset({"read", "write"}): "editor",
}
print(roles[frozenset({"write", "read"})])
print(roles.get(frozenset({"delete"}), "no such role"))

print(len({frozenset({1, 2}), frozenset({2, 1})}))

groups = {frozenset({1, 2}), frozenset({3})}
print(len(groups), frozenset({3}) in groups)

try:
    {{1, 2}, {3}}
except TypeError as error:
    print("TypeError:", error)

try:
    {{1, 2}: "a"}
except TypeError as error:
    print("TypeError:", error)

mutable = {1, 2}
frozen = frozenset(mutable)
mutable.add(3)
print(sorted(mutable), sorted(frozen))
```

## Step 9: Avoid the common set gotchas
Four habits cause most surprises. `{}` is a dict, so use `set()` for an empty set. Sets have no order and no indexing. Changing a set while looping over it raises `RuntimeError`, so loop over `list(s)` or `s.copy()`, or build a new set with a comprehension. And `1`, `1.0`, and `True` count as one item.

```python title="set_gotchas.py" file
s = {1, 2, 3, 4}

try:
    for item in s:
        if item % 2 == 0:
            s.remove(item)
except RuntimeError as error:
    print("RuntimeError:", error)

s = {1, 2, 3, 4}
for item in list(s):
    if item % 2 == 0:
        s.remove(item)
print(sorted(s))

t = {1, 2, 3, 4}
t = {item for item in t if item % 2 != 0}
print(sorted(t))

print(type({}).__name__, type(set()).__name__)
print(sorted(set("abc")), sorted({"abc"}))
print(len({1, 1.0, True}))

numbers = {3, 1, 2}
print(sorted(numbers))
try:
    numbers[0]
except TypeError as error:
    print("TypeError:", error)
```

## How it works
A set stores each item by its hash, in a hash table. That is why items must be hashable, why duplicates are detected at once, and why `x in s`, `add()`, and `remove()` take constant time on average, while `len(s)` is constant always. The cost of set algebra follows the sizes involved: `a | b` is about `len(a) + len(b)`, `a & b` is about `min(len(a), len(b))`, and `a - b` is about `len(a)`. The hash table has no stable order, and string hashing is randomised for each run, which is why printed string sets can differ between runs while the members stay the same.

A frozenset has the same structure but is immutable, so its hash can be computed from its items and it can be used as a dictionary key or a set element. A mixed expression such as `fs | {5}` returns the type of the left operand. Operators need set-like operands on both sides, while the named methods accept any iterable.

## Common errors
### `TypeError: unhashable type: 'list'`
Lists, dicts, and sets cannot be set elements or dictionary keys because they can change. Convert a list to a tuple, or an inner set to a `frozenset`, before adding it.

### `KeyError` from `remove()` or `pop()`
`remove(x)` raises `KeyError` when `x` is missing, and `pop()` raises it on an empty set. Use `discard(x)` for a silent removal, and check `if s:` before popping.

### `{}` creates a dict, not a set
An empty pair of braces is a dictionary, so `{}.add(1)` fails. Write `set()` for an empty set.

### `RuntimeError: Set changed size during iteration`
Adding or removing items while looping over the same set is not allowed. Loop over `list(s)` or `s.copy()`, or build a new set with a comprehension.

### `TypeError: unsupported operand type(s) for |: 'set' and 'list'`
Operators such as `|`, `&`, `-`, and `^` need a set or frozenset on both sides. Use the named method, such as `a.union([7, 8])`, or wrap the list with `set()`.

### `AttributeError: 'frozenset' object has no attribute 'add'`
A frozenset cannot change. Make a regular set with `set(fs)`, change that, and freeze it again with `frozenset()` if needed.

### `TypeError: 'set' object is not subscriptable`
Sets have no positions. Use `in` for membership, or convert with `sorted(s)` or `list(s)` before indexing.

## Recap
- A set stores unique, hashable items with no order and no indexing, so duplicates vanish, `{}` is a dict, and `in` is a fast hash lookup.
- Use `|`, `&`, `-`, and `^` or their named methods for union, intersection, difference, and symmetric difference, and `<=`, `>=`, and `isdisjoint()` to compare sets.
- A frozenset is an immutable, hashable set that works as a dictionary key or set element and raises `AttributeError` if you try to change it.

## Final practice: Student Course Enrollments
The cheat sheet ends with one program that uses sets to compare the courses of two student groups and a frozenset for the mandatory courses, followed by a bonus part. Create `course_enrollments.py` with both parts. The sheet prints the sets directly, and because string order is random, this version wraps each set in `sorted()` so the output is the same on every run.

```python title="course_enrollments.py" file
# Student course enrollments: sets and frozenset
# Sets of strings print in a different order on each run, so every set is
# wrapped in sorted() to make the output the same every time.

# 1. Create the two course sets and print them
group_a_courses = {"Python", "SQL", "Power BI", "Azure"}
group_b_courses = {"Python", "Excel", "Power BI", "GitHub"}
print("Group A courses:", sorted(group_a_courses))
print("Group B courses:", sorted(group_b_courses))

# 2. Union: every course offered to either group
print("All courses (union):", sorted(group_a_courses | group_b_courses))
# same result: group_a_courses.union(group_b_courses)

# 3. Intersection: courses available to both groups
print("Common courses (intersection):", sorted(group_a_courses & group_b_courses))
# same result: group_a_courses.intersection(group_b_courses)

# 4. Difference: courses only Group A has
print("Only in Group A (difference):", sorted(group_a_courses - group_b_courses))
# same result: group_a_courses.difference(group_b_courses)

# 5. Membership test
print("Is GitHub available in Group A?", "GitHub" in group_a_courses)

# 6. Mandatory courses that must never change
mandatory_courses = frozenset({"Python", "SQL", "GitHub"})
print("Mandatory courses:", sorted(mandatory_courses), type(mandatory_courses).__name__)

# Bonus: courses unique to exactly ONE group (symmetric difference)
print("Unique to one group:", sorted(group_a_courses ^ group_b_courses))
print("Only in Group B:", sorted(group_b_courses.difference(group_a_courses)))

# Which mandatory courses is Group A still missing?
print("Group A is missing:", sorted(mandatory_courses - group_a_courses))
print("Group A covers all mandatory courses?", mandatory_courses <= group_a_courses)

# A frozenset cannot be modified
try:
    mandatory_courses.add("Azure")
except AttributeError as err:
    print("Cannot modify a frozenset ->", err)
```
