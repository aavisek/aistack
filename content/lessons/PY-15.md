## Why this matters
Loops often need the position of an item as well as the item: numbered menus, rankings, line numbers, and "which row failed" messages. A hand-written counter is noisy and easy to break with a forgotten `i += 1` or an off-by-one slip. `enumerate` hands you the position and the item together, so the loop says exactly what it means.

## What you will build
Small, standalone Python scripts that replace manual counters with `enumerate`, inspect the pairs it produces, start numbering at 1, pick out first, last, and every other item, find positions, change items in place, and combine it with `zip` and `dict.items()`. You finish with a class roster report that uses all of these ideas.

## Before you start
Use Python 3.10 or newer and create each named file in a practice folder. Every example is independent. Run each file with `python3 filename.py` on macOS/Linux or `py -3 filename.py` in Windows PowerShell.

You should be comfortable with `for` loops and `range` from the previous lessons, and with indexing lists, tuples, and strings. A tuple is a fixed group of values such as `(0, 'h')`, and unpacking means assigning its parts to separate names, as in `i, name = pair`.

## Step 1: See the old way: a manual counter
Before `enumerate`, programs tracked the position by hand. One version keeps a separate counter and adds 1 each pass; the other loops over `range(len(names))` and reads `names[i]`. Both print the same result, but the first breaks silently if you forget `i += 1`, and the second hides the real intent behind index juggling and invites off-by-one slips.

```python title="manual_counter.py" file
names = ["Asha", "Ravi", "Meera"]

i = 0
for name in names:
    print(i, name)
    i += 1  # easy to forget

print("---")
for i in range(len(names)):
    print(i, names[i])  # index juggling
```

```bash title="Terminal" verify="run"
python3 manual_counter.py
```

```text title="Expected output"

1 Ravi
2 Meera
---
0 Asha
1 Ravi
2 Meera
```

The `---` line is only a separator so you can see where the second loop starts.
## Step 2: See what enumerate returns
`enumerate(iterable)` returns a lazy iterator of `(index, item)` tuples. It produces one pair at a time, so printing it directly shows only an object; wrap it in `list()` to look inside, or call `next()` for one pair. An iterator is used up as you take items from it: after two `next()` calls the pairs are gone and `list()` returns an empty list.

```python title="enumerate_object.py" file
print(list(enumerate("hi")))
print(next(enumerate("hi")))

pairs = enumerate(["a", "b"])
print(next(pairs))
print(next(pairs))
print(list(pairs))
print(list(pairs))
print(type(pairs).__name__)
```

```bash title="Terminal" verify="run"
python3 enumerate_object.py
```

```text title="Expected output"
[(0, 'h'), (1, 'i')]
(0, 'h')
(0, 'a')
(1, 'b')
[]
[]
enumerate
```

Because it is lazy, `enumerate` never builds an extra list in memory. Convert it with `list(enumerate(x))` only when you want to print or reuse the pairs.
## Step 3: Use enumerate in a for loop
Unpack each pair in the loop header with `for i, name in enumerate(names):`. The index starts at 0 and there is no counter to forget. If you loop with a single variable, you get the whole tuple instead, which is useful for seeing what is really produced.

```python title="enumerate_basic.py" file
names = ["Asha", "Ravi", "Meera"]

for i, name in enumerate(names):
    print(i, name)

for pair in enumerate(names):
    print(pair)
```

```bash title="Terminal" verify="run"
python3 enumerate_basic.py
```

```text title="Expected output"
(0, 'Asha')
(1, 'Ravi')
(2, 'Meera')
```

## Step 4: Use it on any iterable
`enumerate` accepts anything you can loop over: lists, tuples, strings, files, generators, and dict views. Here `io.StringIO` stands in for an open file so the output is the same on every machine. Looping directly over a dict gives its keys, so `enumerate(prices)` pairs each position with a key.

```python title="enumerate_iterables.py" file
import io

colors = ("red", "green")
for i, color in enumerate(colors):
    print("tuple", i, color)

for i, ch in enumerate("abc"):
    print("string", i, ch)

squares = (n * n for n in range(1, 4))
for i, sq in enumerate(squares):
    print("generator", i, sq)

lines = io.StringIO("first line\nsecond line\n")
for i, line in enumerate(lines):
    print("file", i, line.rstrip())

prices = {"tea": 3, "milk": 2}
for i, key in enumerate(prices):
    print("dict", i, key)
```

```bash title="Terminal" verify="run"
python3 enumerate_iterables.py
```


## Step 5: Start counting from 1
The second argument, `start`, sets the first number: `enumerate(names, start=1)`. Use it for menus, rankings, and line numbers. Watch out: `start` changes the counter, not the list. With `start=1`, `names[n]` is the next item, and on the last pass it raises `IndexError`. Use the loop variable `name`, or `names[n - 1]` when you really need the index.

```python title="start_at_one.py" file
names = ["Asha", "Ravi", "Meera"]

for n, name in enumerate(names, start=1):
    print(f"{n}. {name}")

print("---")
for n, name in enumerate(names, start=1):
    print(n, name, "| names[n - 1] =", names[n - 1])

print("---")
try:
    for n, name in enumerate(names, start=1):
        print(n, names[n])
except IndexError as error:
    print("IndexError:", error)
```

```bash title="Terminal" verify="run"
python3 start_at_one.py
```

```text title="Expected output"
---

```

## Step 6: Find the first, last, and every other item
Because the index is in hand, you can test it directly. `i == 0` is the first item, `i % 2 == 0` selects every other slot, and `i == len(names) - 1` is the last item. The `elif` means index 0 is reported as `first` and is not repeated as an even slot.

```python title="first_last_even.py" file
names = ["Asha", "Ravi", "Meera"]

for i, name in enumerate(names):
    if i == 0:
        print("first:", name)
    elif i % 2 == 0:
        print("even slot:", name)

print("---")
for i, name in enumerate(names):
    if i == len(names) - 1:
        print("last:", name)
```

```bash title="Terminal" verify="run"
python3 first_last_even.py
```

```text title="Expected output"

even slot: Meera
---
last: Meera
```

## Step 7: Find positions with a comprehension
A list comprehension over `enumerate` collects the positions where a condition holds, not the values. `[i for i, n in enumerate(nums) if n > 10]` returns the indexes of the numbers above 10. When nothing matches you get an empty list, so you do not need a special case.

```python title="find_positions.py" file
nums = [5, 12, 7, 20]

print([i for i, n in enumerate(nums) if n > 10])

target = 7
print([i for i, n in enumerate(nums) if n == target])
print([i for i, n in enumerate(nums) if n > 100])
```

```bash title="Terminal" verify="run"
python3 find_positions.py
```

```text title="Expected output"
[1, 3]
[2]
[]
```

## Step 8: Change items in place through the index
Assigning to the loop variable changes nothing in the list: `n = n * 2` rebinds only the local name `n`. To change an item, assign through the index with `nums[i] = n * 2`. This is the main job where you need the position and not only the value. Changing the list items (not its length) while looping is safe.

```python title="change_in_place.py" file
nums = [5, 12, 7, 20]

for n in nums:
    n = n * 2
print(nums)

for i, n in enumerate(nums):
    nums[i] = n * 2
print(nums)
```

```bash title="Terminal" verify="run"
python3 change_in_place.py
```

```text title="Expected output"

[10, 24, 14, 40]
```

## Step 9: Combine with zip and dict.items()
`zip` and `dict.items()` already produce pairs, so `enumerate` wraps a pair inside a pair: `(index, (a, b))`. Unpack it with parentheses around the inner pair: `for i, (p, q) in ...`. Without the parentheses Python tries to unpack the two-item outer tuple into three names and raises `ValueError`.

```python title="zip_and_dict.py" file
a, b = ["x", "y"], [10, 20]
for i, (p, q) in enumerate(zip(a, b)):
    print(i, p, q)

d = {"k1": 1, "k2": 2}
for i, (k, v) in enumerate(d.items()):
    print(i, k, v)

try:
    for i, p, q in enumerate(zip(a, b)):
        print(i, p, q)
except ValueError as error:
    print("ValueError:", error)
```

```text title="Expected output"
ValueError: not enough values to unpack (expected 3, got 2)
```

## Step 10: Know when a plain loop is enough
If you only need the items, a plain `for name in names:` is the simplest form. Using `range(len(names))` with `names[i]` is only worth it in rare cases, such as when you must change the list length by index. Reach for `enumerate` when you need the item and its position together.

```python title="plain_loop.py" file
names = ["Asha", "Ravi", "Meera"]

for name in names:
    print(name)

for i in range(len(names)):
    print(names[i])
```

```bash title="Terminal" verify="run"
python3 plain_loop.py
```

```text title="Expected output"

Ravi
Meera
Asha
Ravi
Meera
```

## How it works
`enumerate(iterable, start=0)` wraps any iterable in a lazy iterator. Each time the loop asks for the next value, it takes the next item from the iterable, pairs it with a counter, and yields the tuple `(index, item)`. The counter begins at `start` and goes up by one, so `start` only changes the numbers you see, never the data. Nothing is copied: no extra list is built unless you call `list()` on it, and like every iterator it can be consumed only once.

Unpacking in the loop header (`for i, item in ...`) turns each tuple into two names. When the item is itself a pair, as with `zip` or `dict.items()`, nest the pattern with parentheses: `for i, (a, b) in ...`. Prefer `enumerate` to `range(len(x))` in almost every case, and when you only need the items, a plain `for item in items` is simplest.

## Common errors
### `ValueError: not enough values to unpack (expected 3, got 2)`
With `zip` or `dict.items()` the item is already a pair, so `for i, p, q in enumerate(zip(a, b))` fails. Put parentheses around the inner pair: `for i, (p, q) in enumerate(zip(a, b))`.

### `IndexError: list index out of range` after `start=1`
`start` changes the counter, not the list, so `names[n]` runs past the end on the last pass. Use the item variable directly, or `names[n - 1]`.

### The list does not change when you assign to the loop variable
`n = n * 2` only rebinds the name `n`. Assign through the index instead: `nums[i] = n * 2`.

### Printing `enumerate(names)` shows an object, not the pairs
`enumerate` is a lazy iterator. Wrap it in `list(...)` to see the pairs, and remember that a second `list()` call on the same iterator returns `[]` because it is already used up.

### Pairs come out as tuples when you use one loop variable
`for pair in enumerate(names)` gives `(0, 'Asha')`. Unpack with `for i, name in enumerate(names)` to get the two values separately.

## Recap
- `enumerate(iterable, start=0)` is a lazy iterator of `(index, item)` tuples that replaces manual counters and `range(len(x))`.
- Use `start=1` for human-friendly numbers, remember it changes only the counter, and use the index (`nums[i] = ...`) to change items in place.
- Nest the pattern for pairs (`for i, (a, b) in ...`), and use a plain `for item in items` when the position is not needed.

## Final practice: Class Roster Report
The cheat sheet has no single closing program, so this one combines its ideas. Create `class_report.py`; it numbers a ranking from 1, pairs names with scores through `zip`, finds positions with a comprehension, changes scores in place, enumerates a dict view, and finishes with the lazy iterator.

```python title="class_report.py" file
students = ["Asha", "Ravi", "Meera", "Kabir"]
scores = [72, 88, 95, 64]
pass_mark = 70

print("Ranking list:")
for rank, name in enumerate(students, start=1):
    print(f"{rank}. {name}")

print("Roster with scores:")
for i, (name, score) in enumerate(zip(students, scores)):
    marker = "first" if i == 0 else "last" if i == len(students) - 1 else "middle"
    print(i, name, score, marker)

passed = [i for i, score in enumerate(scores) if score >= pass_mark]
print("Passed at positions:", passed)

for i, score in enumerate(scores):
    scores[i] = min(score + 5, 100)
print("After curve:", scores)

lookup = {name: score for name, score in zip(students, scores)}
for i, (name, score) in enumerate(lookup.items(), start=1):
    print(f"#{i} {name}={score}")

stream = enumerate(students)
print("Lazy next:", next(stream))
print("Remaining:", list(stream))
```
