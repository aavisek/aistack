## Step 1: Define a generator function with yield

This example focuses on how to define a generator function with yield.

```python title="generators_with_yield_and_next_1.py" file
def squares(limit):
    for number in range(limit):
        yield number * number

print(next(squares(3)))
print(list(squares(3)))
```

```bash title="Terminal" verify="run"
python3 generators_with_yield_and_next_1.py
```

```text title="Expected output"
0
[0, 1, 4]
```

## Step 4: Print streamed values

This example focuses on how to print streamed values.

```python title="generators_with_yield_and_next_4.py" file
def make_values():
    for number in range(1, 4):
        yield number * 10

values = make_values()
print(list(values))
```

## How it works
The syntax `yield value * value` describes the central idea, but the surrounding function or loop determines when work happens. Keep transformations readable, consume iterators deliberately, and make wrapper behavior explicit.

## Common errors
### Building the wrong collection
Choose the collection type from the required output: lists preserve order, sets enforce uniqueness, dictionaries name values, and generators defer work.

### Consuming a generator twice
A generator is an iterator and is normally exhausted after one pass. Create a new generator or materialize intentionally when repeated access is required.

### Hiding behavior in a wrapper
Use `functools.wraps`, preserve arguments, and raise a clear exception when a decorator rejects a call.
