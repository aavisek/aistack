## Why this matters
Modules let you split a program into files with explicit dependencies. Packages use `__init__.py` to define package behavior and a stable public surface.

## What you will build
A runnable set of examples about python imports, modules and __init__.py.

## How it works
Import statements bind names in the importing module.
A package initializer can re-export selected functions.
Aliases should clarify, not obscure, the dependency.

## Common errors
### Repeating code instead of extracting a function
Give a helper one responsibility and return its result.

### Confusing a return value with printed output
Use `return` for callers and `print` only at the boundary.

### Hiding state or dependencies
Prefer explicit parameters and imports over surprising global behavior.
