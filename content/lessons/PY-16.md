## Why this matters
Real data often arrives in parallel lists: names in one, scores in another, cities in a third. Indexing them with `names[i]` and `scores[i]` is noisy and easy to get wrong. `zip` pairs the items by position, so you can loop over them together, build a dictionary, add columns, or turn rows into columns in one readable line.

## What you will build
Small, standalone Python scripts that loop over lists in step, handle lists of different lengths, build dictionaries, unzip and transpose data, compute across lists, and avoid the single-use trap. You finish with a score report program that uses every idea.

## Before you start
Use Python 3.10 or newer (`zip(strict=True)` needs 3.10) and create each named file in a practice folder. Every example is independent. Run each file with `python3 filename.py` on macOS/Linux or `py -3 filename.py` in Windows PowerShell.

This lesson builds on the `for` loops from PY-06 and the dictionaries and tuples from PY-14. You should be comfortable unpacking a pair such as `name, score` in a `for` line and reading `{key: value}` output.

## Step 1: Loop over two lists together
`zip(names, scores)` hands you one item from each list at every turn of the loop. Writing `for name, score in zip(...)` unpacks each pair straight into two variables. Without unpacking, each item is a tuple.

```python title="zip_loop.py" file
names = ["Asha", "Ravi", "Meera"]
scores = [88, 72, 95]

for name, score in zip(names, scores):
    print(name, score)

for pair in zip(names, scores):
    print(pair, type(pair).__name__)
```

```bash title="Terminal" verify="run"
python3 zip_loop.py
```

```text title="Expected output"
Asha 88
Ravi 72
Meera 95
('Asha', 88) tuple
('Ravi', 72) tuple
('Meera', 95) tuple
```

The first loop is the usual form. The second shows what `zip` really produces: a tuple per position.

## Step 2: Pair items by position and join three or more sequences
`zip` is a lazy iterator of tuples: item 0 with item 0, item 1 with item 1, and so on. Lazy means it produces pairs only when asked, so wrap it in `list()` to see them. It accepts any number of sequences, and any iterable works, including strings.

```python title="zip_pairs.py" file
names = ["Asha", "Ravi", "Meera"]
scores = [88, 72, 95]
cities = ["Pune", "Delhi", "Goa"]

print(list(zip("ab", [1, 2])))

z = zip(names, scores)
print(type(z).__name__)

for n, s, c in zip(names, scores, cities):
    print(f"{n} ({c}): {s}")

print(list(zip(names, scores, cities))[0])
print(list(zip(names)))
print(list(zip()))
```

```bash title="Terminal" verify="run"
python3 zip_pairs.py
```

```text title="Expected output"
[('a', 1), ('b', 2)]
zip
Asha (Pune): 88
Ravi (Delhi): 72
Meera (Goa): 95
('Asha', 88, 'Pune')
[('Asha',), ('Ravi',), ('Meera',)]
[]
```

Printing the zip object itself shows only a memory address, so print `list(zip(...))` or loop over it. With one input you get one-item tuples, and with no input you get nothing.

## Step 3: Handle different lengths
`zip` stops at the shortest input and silently drops the rest. That is convenient but can hide a data bug. Pass `strict=True` (Python 3.10+) to raise `ValueError` on a mismatch, or use `itertools.zip_longest` to pad the short input instead.

```python title="zip_lengths.py" file
from itertools import zip_longest as zl

print(list(zip([1, 2, 3], "ab")))
print(list(zl([1, 2, 3], "ab", fillvalue="-")))
print(list(zl([1, 2, 3], "ab")))

try:
    print(list(zip([1, 2, 3], "ab", strict=True)))
except ValueError as error:
    print("ValueError:", error)

print(list(zip([1, 2], "ab", strict=True)))

names = ["Asha", "Ravi", "Meera"]
scores = [88, 72]
print(len(names) == len(scores))
print(dict(zip(names, scores)))
```

```bash title="Terminal" verify="run"
python3 zip_lengths.py
```

```text title="Expected output"
[(1, 'a'), (2, 'b')]
[(1, 'a'), (2, 'b'), (3, '-')]
[(1, 'a'), (2, 'b'), (3, None)]
ValueError: zip() argument 2 is shorter than argument 1
[(1, 'a'), (2, 'b')]
False
{'Asha': 88, 'Ravi': 72}
```

`zip_longest` pads with `None` unless you give `fillvalue`. `strict=True` passes quietly when the lengths match, so it costs nothing on good data. Either compare `len()` first or use `strict=True` when a mismatch would be a mistake.

## Step 4: Build a dictionary
`dict(zip(keys, values))` is the idiomatic way to build a dictionary from two lists. The first list supplies the keys and the second the values. Remember that keys must be unique: a repeated key keeps only the last value.

```python title="zip_dict.py" file
names = ["Asha", "Ravi", "Meera"]
scores = [88, 72, 95]

lookup = dict(zip(names, scores))
print(lookup)
print(lookup["Ravi"])

by_score = dict(zip(scores, names))
print(by_score)

print(dict(zip(["a", "b", "a"], [1, 2, 3])))
print({name: score + 5 for name, score in zip(names, scores)})
```

```bash title="Terminal" verify="run"
python3 zip_dict.py
```

```text title="Expected output"
{'Asha': 88, 'Ravi': 72, 'Meera': 95}
72
{88: 'Asha', 72: 'Ravi', 95: 'Meera'}
{'a': 3, 'b': 2}
{'Asha': 93, 'Ravi': 77, 'Meera': 100}
```

Swapping the arguments flips the dictionary. The duplicate key `"a"` kept the value `3`, so check for repeats before trusting a lookup. A dict comprehension over `zip` lets you change values while you build.

## Step 5: Unzip with zip(*pairs)
`zip(*pairs)` is the reverse of zipping. The `*` spreads the list of pairs into separate arguments, so `zip` regroups them as columns. Unpack the result into one variable per column. The columns come back as tuples.

```python title="zip_unzip.py" file
pairs = [("a", 1), ("b", 2), ("c", 3)]
letters, nums = zip(*pairs)
print(letters, nums)
print(type(letters).__name__)
print(list(letters), list(nums))

print(list(zip(letters, nums)) == pairs)

try:
    first, second = zip(*[])
except ValueError as error:
    print("ValueError:", error)
```

```bash title="Terminal" verify="run"
python3 zip_unzip.py
```

```text title="Expected output"
('a', 'b', 'c') (1, 2, 3)
tuple
['a', 'b', 'c'] [1, 2, 3]
True
ValueError: not enough values to unpack (expected 2, got 0)
```

Zipping the columns back together gives the original pairs. Unzipping an empty list produces no columns, so unpacking into two names fails. Guard against an empty list first.

## Step 6: Compute across lists
Zip lets a comprehension or a generator expression combine matching items from two lists. Use a list comprehension to build a new list, or feed a generator expression to `sum()` for a single total, such as a dot product.

```python title="zip_compute.py" file
q1, q2 = [10, 20, 30], [5, 15, 25]

print([a + b for a, b in zip(q1, q2)])
print(sum(a * b for a, b in zip(q1, q2)))
print([max(a, b) for a, b in zip(q1, q2)])

prices = [2.5, 4.0, 1.5]
quantities = [4, 2, 10]
print(sum(p * q for p, q in zip(prices, quantities)))
```

```bash title="Terminal" verify="run"
python3 zip_compute.py
```

```text title="Expected output"
[15, 35, 55]
1100
[10, 20, 30]
33.0
```

`10*5 + 20*15 + 30*25` is `1100`. The last line is a small order total: each price times its quantity, then added up.

## Step 7: Compare neighbours
Zip a list with itself shifted by one, `temps[1:]`, to see each item next to the one after it. The slice is one item shorter, so `zip` stops cleanly at the last pair and never indexes past the end.

```python title="zip_neighbours.py" file
temps = [20, 22, 21, 25]

diffs = [b - a for a, b in zip(temps, temps[1:])]
print(diffs)
print(list(zip(temps, temps[1:])))
print(any(d < 0 for d in diffs))
print(len(temps), len(diffs))
```

```bash title="Terminal" verify="run"
python3 zip_neighbours.py
```

```text title="Expected output"
[2, -1, 4]
[(20, 22), (22, 21), (21, 25)]
True
4 3
```

Four readings give three differences. This pattern replaces `for i in range(len(temps) - 1)` loops and finds rises, drops, and gaps.

## Step 8: Transpose rows to columns
Because `zip(*pairs)` regroups by position, applying it to a list of rows turns the rows into columns. Each column arrives as a tuple, so wrap it in `list()` when you need lists. This also makes column totals easy.

```python title="zip_transpose.py" file
matrix = [[1, 2, 3], [4, 5, 6]]

print(list(zip(*matrix)))
print([list(col) for col in zip(*matrix)])
print([sum(col) for col in zip(*matrix)])
print([sum(row) for row in matrix])

square = [[1, 2], [3, 4]]
print(list(zip(*zip(*square))))
```

```bash title="Terminal" verify="run"
python3 zip_transpose.py
```

```text title="Expected output"
[(1, 4), (2, 5), (3, 6)]
[[1, 4], [2, 5], [3, 6]]
[5, 7, 9]
[6, 15]
[(1, 2), (3, 4)]
```

A two-row, three-column matrix becomes three rows of two. Summing each column of the transposed view gives column totals, while summing the original rows gives row totals. Transposing twice returns the original shape, but as tuples.

## Step 9: Remember that a zip is single-use
A zip object is an iterator, so once you loop over it or turn it into a list it is used up. A second pass yields nothing and raises no error. If you need the pairs twice, store `list(zip(...))`. A zip also has no length and cannot be indexed.

```python title="zip_single_use.py" file
z = zip("ab", [1, 2])
print(list(z))
print(list(z))

saved = list(zip("ab", [1, 2]))
print(saved)
print(saved)
print(saved[0], len(saved))

z2 = zip("ab", [1, 2])
try:
    z2[0]
except TypeError as error:
    print("TypeError:", error)

try:
    len(zip("ab", [1, 2]))
except TypeError as error:
    print("TypeError:", error)
```

```bash title="Terminal" verify="run"
python3 zip_single_use.py
```

```text title="Expected output"
[('a', 1), ('b', 2)]
[]
[('a', 1), ('b', 2)]
[('a', 1), ('b', 2)]
('a', 1) 2

TypeError: object of type 'zip' has no len()
```

The empty second list is the silent failure to watch for. The saved list can be indexed, measured, and read as often as you like.

## Step 10: Combine zip with enumerate
Use `enumerate` when you also need a counter. Because `zip` yields tuples, wrap the pair in its own parentheses: `for i, (a, b) in enumerate(zip(x, y))`. Pass `start=1` for human-friendly numbering.

```python title="zip_enumerate.py" file
names = ["Asha", "Ravi", "Meera"]
scores = [88, 72, 95]

for i, (name, score) in enumerate(zip(names, scores)):
    print(i, name, score)

for rank, (name, score) in enumerate(zip(names, scores), start=1):
    print(f"#{rank} {name}: {score}")

try:
    for i, name, score in enumerate(zip(names, scores)):
        print(i, name, score)
except ValueError as error:
    print("ValueError:", error)
```

```bash title="Terminal" verify="run"
python3 zip_enumerate.py
```

```text title="Expected output"

#2 Ravi: 72

ValueError: not enough values to unpack (expected 3, got 2)
```

`enumerate` produces `(index, pair)`, which is two items, so leaving out the inner parentheses fails to unpack.

## How it works
`zip(a, b)` calls `iter()` on each input and returns an iterator. Each time you ask for the next item, it takes one value from every input and packs them into a tuple. It stops as soon as any input runs out, which is why the shortest input wins; `strict=True` instead raises `ValueError` if the inputs differ in length, and `zip_longest` keeps going and fills the gaps.

Because a zip is an iterator, it keeps its position and can be consumed only once. Unzipping works because `zip(*pairs)` passes each pair as a separate argument, so the first items of every pair form the first column. Transposing is the same trick applied to rows.

## Common errors
### `ValueError: zip() argument 2 is shorter than argument 1`
`zip(..., strict=True)` found inputs of different lengths. Fix the data so the lists match, or use `zip_longest` when unequal lengths are expected.

### Items are missing and no error appears
Plain `zip` stops at the shortest input and drops the rest without a warning. Compare `len()` first, or pass `strict=True` when every item must be paired.

### The second loop over a zip does nothing
A zip is consumed after one pass. Store `pairs = list(zip(a, b))` and loop over `pairs` as often as you need.

### `TypeError: 'zip' object is not subscriptable`
A zip cannot be indexed, and `len()` fails too. Convert it with `list(zip(...))` first.

### `ValueError: not enough values to unpack`
This happens when `enumerate(zip(a, b))` is unpacked as `i, a, b`, or when `zip(*pairs)` is unpacked from an empty list. Write `i, (a, b)` and check that `pairs` is not empty.

### A dictionary has fewer entries than the lists
`dict(zip(keys, values))` keeps only the last value for a repeated key, and it stops at the shorter list. Check the keys for duplicates and the lengths for a match.

## Recap
- `zip(a, b)` pairs items by position into a lazy, single-use iterator of tuples, stops at the shortest input, and can be told to be strict or to pad with `zip_longest`.
- `dict(zip(keys, values))` builds dictionaries, and `zip(a, b)` supports sums, differences, and neighbour comparisons with `temps[1:]`.
- `zip(*pairs)` unzips and `zip(*matrix)` transposes, `enumerate(zip(x, y))` adds a counter, and `list(zip(...))` stores pairs for reuse.

## Final practice: Score Report
The cheat sheet has no single example program, so this program combines its ideas. Create `score_report.py`; it prints nine labeled results from the same three lists.

```python title="score_report.py" file
# Score Report - the zip ideas from the cheat sheet in one program
from itertools import zip_longest

names = ["Asha", "Ravi", "Meera"]
scores = [88, 72, 95]
cities = ["Pune", "Delhi", "Goa"]
bonus = [5, 3]

# 1. Loop over several lists together
for n, s, c in zip(names, scores, cities):
    print(f"1. {n} ({c}): {s}")

# 2. Different lengths: zip stops, strict raises, zip_longest pads
print("2. Short zip:", list(zip(names, bonus)))
try:
    list(zip(names, bonus, strict=True))
except ValueError as error:
    print("2. Strict:", error)
print("2. Padded:", list(zip_longest(names, bonus, fillvalue=0)))

# 3. Build a dictionary
lookup = dict(zip(names, scores))
print("3. Lookup:", lookup, lookup["Ravi"])

# 4. Compute across lists
totals = [s + b for s, b in zip_longest(scores, bonus, fillvalue=0)]
print("4. Totals:", totals)

# 5. Compare neighbours
gaps = [b - a for a, b in zip(scores, scores[1:])]
print("5. Gaps:", gaps)

# 6. Unzip a list of pairs
pairs = list(zip(names, scores))
who, marks = zip(*pairs)
print("6. Unzipped:", who, marks)

# 7. Transpose a table
table = [names, [str(s) for s in scores], cities]
print("7. Columns:", list(zip(*table))[1])

# 8. Number the rows with enumerate
for i, (n, s) in enumerate(zip(names, scores), start=1):
    print(f"8. #{i} {n}: {s}")

# 9. A zip is single-use
z = zip(names, scores)
print("9. First pass:", len(list(z)), "Second pass:", len(list(z)))
```
