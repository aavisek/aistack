## Why this matters
Default arguments, keyword arguments, and annotations make function interfaces easier to call and understand.

## What you will build
A runnable set of examples about functions: three more features.

## Before you start
Create each named script in a Python 3.10+ environment and run the commands below.

## Step 1: Use a default argument

```python title="py_36_1.py" file
def banner(text, border="-"):
    return f"{border} {text} {border}"

print(banner("Ready"))
```

## Step 3: Annotate a return value

```python title="py_36_3.py" file
def repeat(text: str, times: int = 2) -> str:
    return text * times

print(repeat("go", 3))
```

```bash title="Terminal" verify="run"
python3 py_36_3.py
```

```text title="Expected output"

```

## Step 4: Combine the features

```python title="py_36_4.py" file
def describe(name: str, *, excited: bool = False) -> str:
    ending = "!" if excited else "."
    return f"Hello, {name}{ending}"

print(describe("Mina", excited=True))
```

```bash title="Terminal" verify="run"
python3 py_36_4.py
```

```text title="Expected output"
Hello, Mina!
```

## How it works
Defaults fill omitted arguments.
Keyword calls document which parameter receives each value.
Annotations describe intent without changing runtime behavior.

## Common errors
### Repeating code instead of extracting a function
Give a helper one responsibility and return its result.

### Confusing a return value with printed output
Use `return` for callers and `print` only at the boundary.

### Hiding state or dependencies
Prefer explicit parameters and imports over surprising global behavior.
