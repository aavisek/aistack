## Step 1: Create a generator expression

This example focuses on how to create a generator expression.

```python title="generator_comprehensions_for_mem_1.py" file
numbers = [1, 2, 3, 4, 5]
result = [n * n for n in numbers if n % 2 == 0]
print(result)
```

```bash title="Terminal" verify="run"
python3 generator_comprehensions_for_mem_1.py
```

```text title="Expected output"

```

## Step 4: Print a bounded result

This example focuses on how to print a bounded result.

```python title="generator_comprehensions_for_mem_4.py" file
def make_values():
    for number in range(1, 4):
        yield number * 10

values = make_values()
print(list(values))
```

```bash title="Terminal" verify="run"
python3 generator_comprehensions_for_mem_4.py
```

```text title="Expected output"

```
## How it works
The syntax `(n * n for n in range(1, 6))` describes the central idea, but the surrounding function or loop determines when work happens. Keep transformations readable, consume iterators deliberately, and make wrapper behavior explicit.

## Common errors
### Building the wrong collection
Choose the collection type from the required output: lists preserve order, sets enforce uniqueness, dictionaries name values, and generators defer work.

### Consuming a generator twice
A generator is an iterator and is normally exhausted after one pass. Create a new generator or materialize intentionally when repeated access is required.

### Hiding behavior in a wrapper
Use `functools.wraps`, preserve arguments, and raise a clear exception when a decorator rejects a call.
