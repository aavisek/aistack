## Step 1: Delegate with yield from

This example focuses on how to delegate with yield from.

```python title="yield_from_and_closing_generator_1.py" file
def child():
    yield "a"
    return "done"

def parent():
    result = yield from child()
    yield result

print(list(parent()))
```

```bash title="Terminal" verify="run"
python3 yield_from_and_closing_generator_1.py
```

```text title="Expected output"
['a', 'done']
```

This example focuses on how to print delegated values and cleanup.

## How it works
The syntax `result = yield from child()` describes the central idea, but the surrounding function or loop determines when work happens. Keep transformations readable, consume iterators deliberately, and make wrapper behavior explicit.

## Common errors
### Building the wrong collection
Choose the collection type from the required output: lists preserve order, sets enforce uniqueness, dictionaries name values, and generators defer work.

### Consuming a generator twice
A generator is an iterator and is normally exhausted after one pass. Create a new generator or materialize intentionally when repeated access is required.

### Hiding behavior in a wrapper
Use `functools.wraps`, preserve arguments, and raise a clear exception when a decorator rejects a call.
