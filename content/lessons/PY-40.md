## Why this matters
Returning multiple values is tuple packing and unpacking. It lets a function provide related results while keeping the interface explicit.

## What you will build
A runnable set of examples about handling multiple returns in functions.

## Before you start
Create each named script in a Python 3.10+ environment and run the commands below.

## Step 1: Return two values

```python title="py_40_1.py" file
def min_max(values):
    return min(values), max(values)

print(min_max([3, 1, 8]))
```

```bash title="Terminal" verify="run"
python3 py_40_1.py
```

```text title="Expected output"
(1, 8)
```

## Step 2: Unpack into names

```python title="py_40_2.py" file
def min_max(values):
    return min(values), max(values)

low, high = min_max([3, 1, 8])
print(low, high)
```

```bash title="Terminal" verify="run"
python3 py_40_2.py
```

```text title="Expected output"
1 8
```

## Step 3: Use starred unpacking

```python title="py_40_3.py" file
first, *middle, last = [1, 2, 3, 4]
print(first, middle, last)
```

```bash title="Terminal" verify="run"
python3 py_40_3.py
```

```text title="Expected output"
1 [2, 3] 4
```

## Step 4: Return a meaningful result

```python title="py_40_4.py" file
def min_max(values):
    return min(values), max(values)

def summary(values):
    low, high = min_max(values)
    return {"low": low, "high": high, "count": len(values)}

print(summary([4, 2, 9]))
```

```bash title="Terminal" verify="run"
python3 py_40_4.py
```

```text title="Expected output"
{'low': 2, 'high': 9, 'count': 3}
```

## How it works
Multiple return syntax creates a tuple.
Unpacking makes each result named at the call site.
Return a small structured object when positions become unclear.

## Common errors
### Repeating code instead of extracting a function
Give a helper one responsibility and return its result.

### Confusing a return value with printed output
Use `return` for callers and `print` only at the boundary.

### Hiding state or dependencies
Prefer explicit parameters and imports over surprising global behavior.
