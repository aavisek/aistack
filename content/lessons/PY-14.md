## Why this matters
Almost every program that holds a list also has to walk through it: to print each item, add up prices, keep the valid rows, or reshape the data. A loop that reads items directly is short and hard to get wrong. A loop that changes the list it walks over quietly skips items. This lesson shows the safe pattern for each job.

## What you will build
Small, standalone Python scripts that loop over a list to read, total, filter, transform, and nest its items. You finish with a class gradebook program that combines the patterns and prints a report, the passing students, a ranking, and a cleanup count.

## Before you start
Use Python 3.10 or newer and create each named file in a practice folder. Every example is independent. Run each file with `python3 filename.py` on macOS/Linux or `py -3 filename.py` in Windows PowerShell.

You need the list basics from PY-04: indexing, slicing, `append()`, `remove()`, and the difference between changing a list in place and building a new one. You also need the loop and condition habits from PY-13, such as `for` loops, `if`, and `range()`.

## Step 1: Loop over the items
A `for` loop gives you each item in order, so you rarely need an index. The loop variable keeps the last item after the loop ends. If the list is empty, the body simply never runs, so no special case is needed.

```python title="loop_items.py" file
fruits = ["apple", "banana", "cherry"]

for fruit in fruits:
    print(fruit.upper())

print(fruit)

empty = []
for item in empty:
    print("never printed")
print("empty list: loop body skipped")
```

```bash title="Terminal" verify="run"
python3 loop_items.py
```

```text title="Expected output"
APPLE
BANANA
CHERRY
cherry
empty list: loop body skipped
```

`fruit` is an ordinary name that is rebound on each pass. After the loop it still holds `"cherry"`, which is why the extra `print(fruit)` works.

## Step 2: Total and average
To total a list, start an accumulator at zero and add each item to it. The average is the total divided by `len()`. Dividing by the length of an empty list raises `ZeroDivisionError`, so guard it with `if scores:`. The built-in `sum()` does the same job in one call.

```python title="total_average.py" file
nums = [4, 8, 15, 16]

total = 0
for n in nums:
    total += n
print(total, total / len(nums))
print(sum(nums), sum(nums) / len(nums))

scores = []
try:
    print(sum(scores) / len(scores))
except ZeroDivisionError as error:
    print("ZeroDivisionError:", error)

if scores:
    print(sum(scores) / len(scores))
else:
    print("no scores yet")
```

```bash title="Terminal" verify="run"
python3 total_average.py
```

```text title="Expected output"
43 10.75
43 10.75
ZeroDivisionError: division by zero
no scores yet
```

`/` always returns a float, so the average prints as `10.75`. An empty list has a total of `0` but no average, so the guard matters.

## Step 3: Filter into a new list
To keep only some items, start with an empty list, test each item, and `append()` the ones that pass. The same shape transforms items: append a changed value instead of the original. The loop builds a new list and leaves the source list alone.

```python title="filter_loop.py" file
nums = [4, 8, 15, 16]

evens = []
for n in nums:
    if n % 2 == 0:
        evens.append(n)
print(evens)

squares = []
for n in nums:
    squares.append(n * n)
print(squares)

print(nums)
```

```bash title="Terminal" verify="run"
python3 filter_loop.py
```

```text title="Expected output"
[4, 8, 16]
[16, 64, 225, 256]
[4, 8, 15, 16]
```

`n % 2 == 0` is true when `n` divides evenly by 2. The last line confirms that `nums` was only read, never changed.

## Step 4: The list comprehension shortcut
A list comprehension writes the same loop in one line: `[expression for item in list if condition]`. The `if` part is optional and filters; the expression part transforms. Read it from left to right as "give me this, for each item, if this is true".

```python title="comprehension.py" file
nums = [4, 8, 15, 16]
fruits = ["apple", "banana", "cherry"]

print([n for n in nums if n % 2 == 0])
print([n * n for n in nums])
print([f[0] for f in fruits])

evens = []
for n in nums:
    if n % 2 == 0:
        evens.append(n)
print(evens == [n for n in nums if n % 2 == 0])

print([n if n % 2 == 0 else 0 for n in nums])
print([n for n in []])
```

```bash title="Terminal" verify="run"
python3 comprehension.py
```

```text title="Expected output"
[4, 8, 16]
[16, 64, 225, 256]
['a', 'b', 'c']
True
[4, 8, 0, 16]
[]
```

The loop from Step 3 and the comprehension give equal lists. An `if ... else` placed before the `for` transforms every item instead of dropping some, and a comprehension over an empty list is an empty list.

## Step 5: Unpack tuples in the header
When a list holds pairs, name the parts in the loop header: `for name, mark in pairs`. Python unpacks each tuple into the names for you, which reads better than `pair[0]` and `pair[1]`. Each tuple must have exactly as many items as there are names.

```python title="unpack_pairs.py" file
pairs = [("Asha", 88), ("Ravi", 72)]

for name, mark in pairs:
    print(f"{name}: {mark}")

for pair in pairs:
    print(pair)

try:
    for name, mark in [("Asha", 88), ("Mei",)]:
        print(name, mark)
except ValueError as error:
    print("ValueError:", error)
```

```bash title="Terminal" verify="run"
python3 unpack_pairs.py
```

```text title="Expected output"
Asha: 88
Ravi: 72
('Asha', 88)
('Ravi', 72)
Asha 88
ValueError: not enough values to unpack (expected 2, got 1)
```

Without unpacking, `pair` is the whole tuple. A tuple of the wrong length raises `ValueError`, but only when the loop reaches it, so the first row printed before the error.

## Step 6: Loop by index (use sparingly)
`range(len(fruits))` gives the positions `0` to `len(fruits) - 1`, so `fruits[i]` reads each item. Prefer `enumerate()` when you need the position and the item together. Use an index only when you must change items in place, because rebinding the loop variable does not change the list.

```python title="index_loop.py" file
fruits = ["apple", "banana", "cherry"]

for i in range(len(fruits)):
    print(i, fruits[i])

for i, fruit in enumerate(fruits):
    print(i, fruit)

nums = [4, 8, 15, 16]
for n in nums:
    n = n * 2
print(nums)

for i in range(len(nums)):
    nums[i] = nums[i] * 2
print(nums)
```

```bash title="Terminal" verify="run"
python3 index_loop.py
```

```text title="Expected output"
0 apple
1 banana
2 cherry
0 apple
1 banana
2 cherry
[4, 8, 15, 16]
[8, 16, 30, 32]
```

`n = n * 2` only rebinds the name `n`, so the list is unchanged. Assigning to `nums[i]` replaces the item in the list. The next sheet in the series covers `enumerate()` in more depth.

## Step 7: Loop over part of a list, reversed, or sorted
You can loop over a slice, a reversed view, or a sorted copy without changing the original list. A slice such as `nums[:2]` or `nums[::-1]` builds a new list. `reversed(nums)` builds no list at all: it returns an iterator that walks backwards. `sorted(nums, reverse=True)` returns a new sorted list.

```python title="parts_reversed_sorted.py" file
nums = [4, 8, 15, 16]

for n in nums[:2]:
    print("first two:", n)

for n in nums[::-1]:
    print("slice reversed:", n)

for n in reversed(nums):
    print("reversed:", n)

for n in sorted(nums, reverse=True):
    print("sorted descending:", n)

print(nums)
print(reversed(nums) is nums, type(reversed(nums)).__name__)
```


```text title="Expected output"
sorted descending: 15
sorted descending: 8
sorted descending: 4
```

`nums` is still `[4, 8, 15, 16]` after every loop. `reversed()` returns a separate iterator object, not the list itself, so the identity test is `False`.

## Step 8: Never remove items while looping
Removing an item from the list you are looping over shifts the later items left, and the loop then jumps past the neighbour. Build a new list with a comprehension, or loop over a copy with `a[:]` while you change the original.

```python title="remove_while_looping.py" file
a = [1, 3, 5, 2]
for x in a:
    if x % 2 == 1:
        a.remove(x)
print(a)

a = [1, 3, 5, 2]
a = [x for x in a if x % 2 == 0]
print(a)

a = [1, 3, 5, 2]
for x in a[:]:
    if x % 2 == 1:
        a.remove(x)
print(a)
```

```bash title="Terminal" verify="run"
python3 remove_while_looping.py
```

```text title="Expected output"
[3, 2]
[2]
[2]
```

In the first loop, removing `1` moves `3` into position 0, but the loop moves on to position 1 and misses it. It then removes `5`, so `3` survives and the result is `[3, 2]`. Both fixes give the correct `[2]`. The same rule applies to adding items: never add to a list while looping over it.

## Step 9: Lists of lists
A list can hold other lists. Loop over the outer list to get each row, then loop over the row for its values, or use a comprehension with two `for` parts. In `[v for row in grid for v in row]` the loops read in the same order as nested loops.

```python title="nested_lists.py" file
grid = [[1, 2], [3, 4], [5, 6]]

for row in grid:
    print(row, sum(row))

flat = [v for row in grid for v in row]
print(flat)

flat_loop = []
for row in grid:
    for v in row:
        flat_loop.append(v)
print(flat_loop == flat)

for r, row in enumerate(grid):
    for c, v in enumerate(row):
        if v % 2 == 0:
            print(f"row {r}, column {c}: {v}")
```

```bash title="Terminal" verify="run"
python3 nested_lists.py
```

```text title="Expected output"
[1, 2] 3
[3, 4] 7
[5, 6] 11
[1, 2, 3, 4, 5, 6]
True
row 0, column 1: 2
row 1, column 1: 4
row 2, column 1: 6
```

Flattening turns the three rows into one list of six values. The nested `enumerate()` loops give the row and column of each value.

## Step 10: Handy built-ins for lists
Many hand-written loops already exist as built-ins. `len()` counts, `sum()`, `min()`, and `max()` summarise numbers, `sorted()` returns a new sorted list, `any()` and `all()` test truthiness, `in` tests membership, and `count()` and `index()` locate values.

```python title="builtins_demo.py" file
x = [4, 8, 15, 16]

print(len(x))
print(sum(x), min(x), max(x))
print(sorted(x, reverse=True), x)
print(any(n > 15 for n in x), all(n > 4 for n in x))
print(any([]), all([]))
print(8 in x, 9 in x)
print(x.count(8), x.index(8))

flags = [0, "", None]
print(any(flags), all([1, "a", True]))
```

```bash title="Terminal" verify="run"
python3 builtins_demo.py
```

```text title="Expected output"
4
43 4 16
[16, 15, 8, 4] [4, 8, 15, 16]
True False
False True
True False
1 1
False True
```

`any([])` is `False` because no item is truthy, while `all([])` is `True` because no item is falsy. `any` and `all` accept a generator expression, so they stop at the first deciding item. `index()` raises `ValueError` when the value is missing, as in PY-04.

## How it works
A `for` loop asks the list for an iterator and takes one item per pass until the iterator is exhausted. The iterator remembers a position number, not a copy of the list. That explains the removal bug: when an item is removed, the later items shift left but the position keeps counting up, so one neighbour is skipped. Looping over a copy with `a[:]` or building a new list avoids the problem.

Loops that build results follow one of two shapes. An accumulator (`total += n`) folds the items into one value, and `append()` inside the loop builds a new list. A list comprehension is the one-line form of the second shape. Slices and `sorted()` make new lists, `reversed()` makes an iterator, and `enumerate()` pairs each item with its position. Use the built-ins `sum`, `min`, `max`, `any`, and `all` when they fit instead of writing the loop yourself.

## Common errors
### The loop skips items after `remove()`
Removing from the list you are looping over shifts later items left, so the loop jumps over one. Build a new list with `[x for x in a if keep(x)]`, or loop over a copy with `for x in a[:]`.

### `ZeroDivisionError: division by zero`
An average of an empty list divides by `len([])`, which is `0`. Check `if scores:` before dividing and decide what an empty list should report.

### `ValueError: not enough values to unpack (expected 2, got 1)`
The loop header names more variables than the tuple holds. Make every item the same shape, or loop over the whole item and check `len()` first.

### The list does not change after `n = n * 2`
Assigning to the loop variable rebinds a name and does not touch the list. Assign to `nums[i]` in a `range(len(nums))` loop, or build a new list with a comprehension.

### `IndexError: list index out of range` in an index loop
A hand-written range such as `range(len(a) + 1)` goes one position too far. Loop over `range(len(a))`, or loop over the items directly and avoid the index.

### `print(reversed(nums))` shows an object, not a list
`reversed()` returns an iterator. Loop over it directly, or wrap it with `list(reversed(nums))` when you need the list.

## Recap
- Loop over the items directly, unpack tuples in the header, and use `range(len())` or `enumerate()` only when you need the position.
- Build results with an accumulator, `append()` in a loop, or a list comprehension, and use `sum`, `min`, `max`, `any`, and `all` when they fit.
- Never add or remove items from the list you are looping over; build a new list or loop over a copy such as `a[:]`.

## Final practice: Class Gradebook
The cheat sheet has no single example program, so this final program combines its ideas. Create `gradebook.py`; it loops over a list of tuples, totals and averages marks, filters with a comprehension, flattens nested lists, uses `any`, `all`, `max`, and `min`, ranks with `sorted()` and `enumerate()`, and cleans up the list without removing items while looping. The `key=lambda s: sum(s[1])` part tells `sorted()` to compare students by their total marks.

```python title="gradebook.py" file
# Class Gradebook - combines the loop patterns from the cheat sheet
students = [("Asha", [88, 92, 79]), ("Ravi", [72, 65, 80]), ("Mei", [95, 90, 98]), ("Tom", [])]

print("1. Report:")
for name, marks in students:
    if marks:
        print(f"   {name}: total {sum(marks)}, average {sum(marks) / len(marks):.1f}")
    else:
        print(f"   {name}: no marks yet")

# Filter with a comprehension: keep only students who have marks
scored = [(name, marks) for name, marks in students if marks]
print("2. Students with marks:", [name for name, marks in scored])

# Total with a loop, filter into a new list, and transform in one line
passed = []
for name, marks in scored:
    average = sum(marks) / len(marks)
    if average >= 75:
        passed.append(name)
print("3. Passed (average 75 or more):", passed)

# Flatten the list of lists, then use built-ins
all_marks = [m for _, marks in scored for m in marks]
print("4. All marks:", all_marks)
print("5. Highest, lowest, count:", max(all_marks), min(all_marks), len(all_marks))
print("6. Everyone above 60:", all(m > 60 for m in all_marks))
print("7. Any perfect score:", any(m == 100 for m in all_marks))

# Loop in sorted order, best total first, with enumerate for the rank
ranking = sorted(scored, key=lambda s: sum(s[1]), reverse=True)
for rank, (name, marks) in enumerate(ranking, start=1):
    print(f"8.{rank} {name} - {sum(marks)}")

# Safe cleanup: build a new list instead of removing while looping
students = [s for s in students if s[1]]
print("9. After cleanup:", len(students), "students")
```

```bash title="Terminal" verify="run"
python3 gradebook.py
```

```text title="Expected output"
   Tom: no marks yet

3. Passed (average 75 or more): ['Asha', 'Mei']
4. All marks: [88, 92, 79, 72, 65, 80, 95, 90, 98]
5. Highest, lowest, count: 98 65 9
6. Everyone above 60: True
```

- Tom has an empty list of marks, so the guard `if marks:` prevents a `ZeroDivisionError` and the report prints a message instead.
- Output line 4 uses `_` for the unused student name; the double `for` reads as an outer loop over students and an inner loop over marks.
- `sorted()` and the comprehension in the cleanup build new lists, so no item is ever removed from a list that is being looped over.
