## Why this matters
Some logic belongs conceptually to a class but needs neither an instance nor the class itself. A static method communicates that relationship while keeping the function namespaced and easy to discover.

## What you will build
An `Order` class with a static validation helper and an instance method that uses it.

## Before you start
Create `static_methods.py` and run it with Python 3.10 or newer.

## Step 1: Define a static method
`@staticmethod` prevents Python from injecting `self` or `cls`.

```python title="static_methods.py" file
class Order:
    @staticmethod
    def valid_quantity(quantity):
        return isinstance(quantity, int) and quantity > 0


print(Order.valid_quantity(3))
print(Order.valid_quantity(0))
print(Order().valid_quantity(2))
```

```bash title="Terminal" verify="run"
python3 static_methods.py
```

```text title="Expected output"
True
False
True
```

## Step 2: Use a helper from an instance method
The helper does not read object state, so it remains static.

```python title="order_validation.py" file
class Order:
    def __init__(self, quantity):
        if not self.valid_quantity(quantity):
            raise ValueError("quantity must be positive")
        self.quantity = quantity

    @staticmethod
    def valid_quantity(quantity):
        return isinstance(quantity, int) and quantity > 0


print(Order(4).quantity)
try:
    Order(-1)
except ValueError as error:
    print(error)
```

```bash title="Terminal" verify="run"
python3 order_validation.py
```

```text title="Expected output"
4
quantity must be positive
```

## Step 3: Compare a plain function
A module-level function is also valid when the behavior is not specifically part of the class vocabulary. Choose the location that makes ownership clear.

```python title="helper_choices.py" file
def is_positive(value):
    return value > 0


class Order:
    @staticmethod
    def valid_quantity(value):
        return isinstance(value, int) and is_positive(value)


print(is_positive(2), Order.valid_quantity(2))
```

```bash title="Terminal" verify="run"
python3 helper_choices.py
```

```text title="Expected output"
True True
```

## How it works
A normal instance method receives `self`; a class method receives `cls`; a static method receives neither automatically. Static methods are descriptors that return the underlying function without binding an object.

## Verify against the requirements
- [x] A static method can be called through the class → Step 1
- [x] It receives no implicit instance → Step 1
- [x] It is appropriate for class-related stateless behavior → Step 2

## Common errors
### Adding self to a static helper unnecessarily
If the method does not use object state, omit the parameter.

### Calling instance data from a static method
There is no implicit instance; pass required data explicitly.

### Making every utility static
Use a module function when the behavior has no meaningful class relationship.

## Recap
- Static methods are namespaced functions without implicit binding.
- Use them for stateless behavior related to a class.
- Prefer a module function when no class relationship exists.
