## Why this matters
A complete function design includes a name, parameters, a return contract, and tests for edge cases. This lesson combines the patterns into a small reusable tool.

## What you will build
A runnable set of examples about functions in python.

## Before you start
Create each named script in a Python 3.10+ environment and run the commands below.

## Step 1: Define a clear contract

```python title="py_44_1.py" file
def percent(part, whole):
    if whole == 0: raise ValueError("whole cannot be zero")
    return round(part / whole * 100, 1)

print(percent(2, 5))
```

```bash title="Terminal" verify="run"
python3 py_44_1.py
```

```text title="Expected output"
40.0
```

## Step 2: Handle an edge case

```python title="py_44_2.py" file
def parse_score(text):
    score = int(text)
    if not 0 <= score <= 100: raise ValueError("score out of range")
    return score

try: print(parse_score("105"))
except ValueError as error: print(type(error).__name__, error)
```

```bash title="Terminal" verify="run"
python3 py_44_2.py
```

```text title="Expected output"
ValueError score out of range
```

## Step 3: Compose helpers

```python title="py_44_3.py" file
def report(text):
    words = text.split()
    return {"words": len(words), "unique": len(set(words))}

print(report("red blue red"))
```

```bash title="Terminal" verify="run"
python3 py_44_3.py
```

## Step 4: Test expected behavior

```python title="py_44_4.py" file
def percent(part, whole):
    if whole == 0: raise ValueError("whole cannot be zero")
    return round(part / whole * 100, 1)

def report(text):
    words = text.split()
    return {"words": len(words), "unique": len(set(words))}

assert percent(1, 4) == 25.0
assert report("a a b")["unique"] == 2
print("tests passed")
```


## Common errors
### Repeating code instead of extracting a function
Give a helper one responsibility and return its result.

### Confusing a return value with printed output
Use `return` for callers and `print` only at the boundary.

### Hiding state or dependencies
Prefer explicit parameters and imports over surprising global behavior.
