## Why this matters
Python functions are objects: they can be stored, passed, returned, and decorated. Recognizing these forms helps you build flexible APIs.

## What you will build
A runnable set of examples about function types in python.

## Before you start
Create each named script in a Python 3.10+ environment and run the commands below.

## Step 1: Store and call a function

```python title="py_42_1.py" file
def shout(text):
    return text.upper()

operation = shout
print(operation("hello"))
```

```bash title="Terminal" verify="run"
python3 py_42_1.py
```

```text title="Expected output"

```

## Step 2: Pass a function as data

```python title="py_42_2.py" file
def apply(function, value):
    return function(value)

print(apply(str.upper, "ready"))
```

```bash title="Terminal" verify="run"
python3 py_42_2.py
```


## Step 3: Return a function

```python title="py_42_3.py" file
def make_power(exponent):
    return lambda value: value ** exponent

square = make_power(2)
print(square(5))
```

```bash title="Terminal" verify="run"
python3 py_42_3.py
```

```text title="Expected output"
25
```

## Step 4: Use a callable object

```python title="py_42_4.py" file
class Prefix:
    def __init__(self, value): self.value = value
    def __call__(self, text): return self.value + text

print(Prefix("Hi " )("Ada"))
```

```bash title="Terminal" verify="run"
python3 py_42_4.py
```

```text title="Expected output"
Hi Ada
```

## How it works
Functions can be assigned like other values.
A callable contract can accept a function or object with `__call__`.
Returning closures preserves configuration.

## Common errors
### Repeating code instead of extracting a function
Give a helper one responsibility and return its result.

### Confusing a return value with printed output
Use `return` for callers and `print` only at the boundary.

### Hiding state or dependencies
Prefer explicit parameters and imports over surprising global behavior.
