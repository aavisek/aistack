## Why this matters
`self` is the link between a method and the object that called it. Once you understand that link, instance state, method calls, and common error messages become much easier to reason about.

## What you will build
A `Counter` class and equivalent explicit method calls that reveal what Python passes automatically.

## Before you start
Create `self_demo.py` and run it with Python 3.10 or newer.

## Step 1: Store state through self
Assigning `self.value` stores data on the current object.

```python title="self_demo.py" file
class Counter:
    def __init__(self, start):
        self.value = start

    def increment(self):
        self.value += 1


counter = Counter(4)
counter.increment()
print(counter.value)
```

```bash title="Terminal" verify="run"
python3 self_demo.py
```

```text title="Expected output"
5
```

## Step 2: See the explicit call
`counter.increment()` is equivalent to passing `counter` as the first argument to the function stored on the class.

```python title="explicit_self.py" file
class Counter:
    def increment(self):
        self.value += 1


counter = Counter()
counter.value = 4
counter.increment()
Counter.increment(counter)
print(counter.value)
```

```bash title="Terminal" verify="run"
python3 explicit_self.py
```

```text title="Expected output"
6
```

## Step 3: Keep self and local names distinct
A local variable disappears when the method returns. An attribute on `self` remains on the object.

```python title="local_vs_attribute.py" file
class Greeting:
    def make(self, name):
        message = f"Hello, {name}"
        self.last_message = message
        return message


greeting = Greeting()
print(greeting.make("Mina"))
print(greeting.last_message)
```

```bash title="Terminal" verify="run"
python3 local_vs_attribute.py
```

```text title="Expected output"
Hello, Mina
Hello, Mina
```

## Step 4: Avoid the missing-self error
An instance method needs an instance. Calling it on the class without an argument produces a `TypeError`.

```python title="missing_self.py" file
class Counter:
    def value_text(self):
        return "ready"


try:
    Counter.value_text()
except TypeError as error:
    print(type(error).__name__)

print(Counter().value_text())
```

```bash title="Terminal" verify="run"
python3 missing_self.py
```

```text title="Expected output"
TypeError
ready
```

## How it works
`self` is a conventional parameter name, not a reserved word. Python binds an instance method when it is accessed through an instance and supplies that instance as the first argument. The name can technically differ, but using `self` is the universal convention.

## Common errors
### Omitting `self` from a method definition
The call will pass an argument that the method does not accept.

### Writing `value += 1` instead of `self.value += 1`
The former refers to a local name and usually raises `NameError`.

### Treating self as a class-wide variable
Each instance receives its own `self`.

## Recap
- `self` connects a method to its receiving instance.
- Use `self.attribute` for state that survives the method call.
- Bound and explicit method calls pass the same instance.
