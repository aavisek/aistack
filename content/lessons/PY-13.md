## Why this matters
A loop runs a block of code many times, so you write the instructions once and the same code handles 3 items or 3 million. Totals, searches, tables, and file processing all depend on loops. Knowing what `range()` produces and what a `for` loop walks through prevents the off-by-one and "wrong variable" bugs that beginners meet first.

## What you will build
Small, standalone Python scripts that repeat work with `for` and `range()`, add up and compare values, loop over lists, strings, dictionaries, and file lines, nest one loop inside another, and choose between `for` and `while`. You finish with a loop toolkit program that combines the sheet's ideas.

## Before you start
Use Python 3.10 or newer and create each named file in a practice folder. Every example is independent. Run each file with `python3 filename.py` on macOS/Linux or `py -3 filename.py` in Windows PowerShell.

You should know variables and `print()` from PY-02 and the collections and conditions from the earlier lessons, because loops work with lists and dictionaries and use `if` inside the body. If a program ever runs away and never stops, press Ctrl+C in the terminal to interrupt it.

## Step 1: Repeat work with a for loop
A `for` loop runs the indented lines below it once for every value it is given. Here `range(3)` gives the values 0, 1, and 2, so the `print()` call runs three times and `i` holds the current value. Changing the number changes how often the body runs; the code stays the same. A line that is not indented is outside the loop and runs once, after the loop ends.

```python title="first_loop.py" file
for i in range(3):
    print("Hello", i)

print("---")

for i in range(5):
    print("Hello", i)
print("Done")
```

```bash title="Terminal" verify="run"
python3 first_loop.py
```

```text title="Expected output"
Hello 0
Hello 1
Hello 2
---
Hello 0
Hello 1
Hello 2
Hello 3
Hello 4
Done
```

`range(3)` yields exactly three values, starting at 0. The second loop only needed `3` changed to `5` to repeat five times.

## Step 2: Generate numbers with range()
`range()` produces numbers on demand and has three forms: `range(stop)`, `range(start, stop)`, and `range(start, stop, step)`. The stop value is never included. A negative step counts down, and wrapping the range in `list()` shows its values. A range that cannot reach its stop is simply empty.

```python title="range_forms.py" file
print(list(range(5)))
print(list(range(2, 6)))
print(list(range(0, 10, 3)))
print(list(range(5, 0, -1)))

print(list(range(1, 5)))
print(list(range(1, 6)))

print(len(range(5)), list(range(3, 3)), list(range(5, 1)))
print(range(4))
```

```bash title="Terminal" verify="run"
python3 range_forms.py
```

```text title="Expected output"
[0, 1, 2, 3, 4]
[2, 3, 4, 5]
[0, 3, 6, 9]
[5, 4, 3, 2, 1]
[1, 2, 3, 4]
[1, 2, 3, 4, 5]
5 [] []
range(0, 4)
```

Someone who writes `range(1, 5)` expecting 5 gets 1 to 4; use `range(1, 6)`. `range(n)` always yields exactly `n` values. Printing a range shows only its description, because the numbers are produced when the loop asks for them.

## Step 3: Build a result with the accumulator pattern
Start with a neutral value before the loop, update it inside the loop, and use it after the loop. The neutral value is `0` for sums and counts and `""` for text. `total += n` is short for `total = total + n`. The same shape works for numbers from `range()`, items in a list, and characters in a string.

```python title="accumulator.py" file
total = 0
for n in range(1, 6):
    total += n  # 1+2+3+4+5
print(total)

prices = [4.5, 3.0, 2.5]
bill = 0
for price in prices:
    bill += price
print("Bill:", bill)

word = "loop"
shout = ""
for letter in word:
    shout += letter.upper()
print(shout)

count = 0
for n in range(1, 11):
    if n % 3 == 0:
        count += 1
print("Multiples of 3 up to 10:", count)
```

```bash title="Terminal" verify="run"
python3 accumulator.py
```

```text title="Expected output"
15
Bill: 10.0
LOOP
Multiples of 3 up to 10: 3
```

The `print(total)` line is dedented, so it runs once after the loop and shows the final value. If it were indented, it would print on every pass.

## Step 4: See what a for loop can walk through
The anatomy is `for item in iterable:` followed by an indented body that runs once per value. The loop ends when the values run out. Lists, tuples, and sets give the next item, strings give the next character, ranges give the next integer, and a dictionary gives the next key. Use `.values()` or `.items()` for the values or the key-value pairs. An empty collection means the body never runs.

```python title="for_anatomy.py" file
for item in ["pen", "book", "lamp"]:
    print("list item:", item)

for item in ("red", "green"):
    print("tuple item:", item)

for item in {"only"}:
    print("set item:", item)

for item in "abc":
    print("str character:", item)

for item in range(2):
    print("range integer:", item)

ages = {"Ana": 31, "Ben": 27}

for key in ages:
    print("dict key:", key)

for value in ages.values():
    print("dict value:", value)

for key, value in ages.items():
    print("dict pair:", key, value)

for item in []:
    print("never printed")
print("empty collection: the body never ran")
```

```bash title="Terminal" verify="run"
python3 for_anatomy.py
```

```text title="Expected output"

list item: lamp
tuple item: red
tuple item: green
set item: only
str character: a
str character: b
str character: c
range integer: 0
range integer: 1
dict key: Ana
dict key: Ben
dict value: 31
dict value: 27
dict pair: Ana 31
dict pair: Ben 27
empty collection: the body never ran
```

The set has one item on purpose: a set does not promise any order, so never rely on the order of a larger one. Name the loop variable after what it holds, such as `for student in students`, not `for x in y`.

## Step 5: Loop over the lines of a file
An open file is also something a `for` loop can walk through: each pass gives the next line, including its trailing newline. The script first writes a small file so it is standalone. `repr()` shows the hidden `\n`, and `strip()` removes it before printing.

```python title="file_lines.py" file
with open("notes.txt", "w", encoding="utf-8") as handle:
    handle.write("first line\nsecond line\nthird line\n")

with open("notes.txt", encoding="utf-8") as handle:
    for line in handle:
        print(repr(line))

with open("notes.txt", encoding="utf-8") as handle:
    for number, line in enumerate(handle, start=1):
        print(number, line.strip())
```

```bash title="Terminal" verify="run"
python3 file_lines.py
```

```text title="Expected output"
'first line\n'
'second line\n'
'third line\n'
1 first line
2 second line
3 third line
```

The `with` block closes the file for you. `enumerate()` adds a counter to any loop and is covered in its own lesson; here it only numbers the lines.

## Step 6: Find the maximum
To find the largest value, start with the first item, then compare every item with the best one so far and replace it when a larger one appears. Starting from the first item is safer than starting from `0`: with all-negative data, a start value of `0` is never beaten and gives a wrong answer. The smallest value is the same pattern with `<`.

```python title="find_maximum.py" file
nums = [4, 9, 2]
biggest = nums[0]
for n in nums:
    if n > biggest:
        biggest = n
print(biggest)

temps = [-4, -9, -2]
coldest = temps[0]
for t in temps:
    if t < coldest:
        coldest = t
print(coldest, min(temps), max(nums))

best = 0
for t in temps:
    if t > best:
        best = t
print("Wrong start value:", best)
```

```bash title="Terminal" verify="run"
python3 find_maximum.py
```

```text title="Expected output"
9
-9 -9 9
Wrong start value: 0
```

Python's built-in `min()` and `max()` give the same answers; writing the loop once shows how they work and teaches the compare-and-replace pattern.

## Step 7: Nest one loop inside another
The inner loop runs completely for every pass of the outer loop. With 4 outer passes and 5 inner passes, the inner body runs 4 × 5 = 20 times. Nested loops build tables and grids: here the row and column numbers are multiplied, and the f-string `{row * col:3}` pads each product to a width of 3 so the columns line up.

```python title="nested_loops.py" file
for row in range(1, 4):
    line = ""
    for col in range(1, 4):
        line += f"{row * col:3}"
    print(line)

print("---")

for outer in range(2):
    for inner in range(3):
        print("outer", outer, "inner", inner)

print("---")

passes = 0
for outer in range(4):
    for inner in range(5):
        passes += 1
print("Inner body ran", passes, "times")
```

```bash title="Terminal" verify="run"
python3 nested_loops.py
```

```text title="Expected output"
  1  2  3
  2  4  6
  3  6  9
---
outer 0 inner 0
outer 0 inner 1
outer 0 inner 2
outer 1 inner 0
outer 1 inner 1
outer 1 inner 2
---
Inner body ran 20 times
```

Each row starts with `line = ""`, so every row begins empty. `print(line)` is aligned with the inner `for`, so it runs once per row rather than once per cell.

## Step 8: Know the loop variable and the underscore
The loop variable is an ordinary variable, and it still exists after the loop, holding the last value it was given. `pass` is an empty body placeholder when a block needs a line but has nothing to do. When you need to repeat something but do not need the value, name the variable `_` by convention. If the loop never runs, the variable is never created.

```python title="loop_variable.py" file
for i in range(3):
    pass  # empty body placeholder
print(i)  # → 2

for _ in range(2):  # _ = value not needed
    print("hi")

for letter in "xyz":
    last = letter
print(letter, last)

try:
    for unused in range(0):
        pass
    print(unused)
except NameError:
    print("NameError: an empty loop never created the variable")
```

```bash title="Terminal" verify="run"
python3 loop_variable.py
```

```text title="Expected output"
2
hi
hi
z z
NameError: an empty loop never created the variable
```

After `range(3)`, `i` is 2 and not 3 because the last value `range(3)` gives is 2. Do not rely on the variable after a loop that might not run.

## Step 9: Choose between for and while
Use `for` when you have a collection or know how many times to repeat. Use `while` when you repeat until a condition changes, such as input, retries, or a game. A `for` countdown and a `while` countdown can give the same result, but the `while` loop must change its own variable or it never stops. Every example here has a built-in end.

```python title="for_vs_while.py" file
for n in range(3, 0, -1):
    print("for countdown:", n)

n = 3
while n > 0:
    print("while countdown:", n)
    n -= 1

balance = 100
months = 0
while balance < 150:
    balance += 20
    months += 1
print("Months needed:", months, "Balance:", balance)

attempts = ["wrong", "wrong", "secret"]
tries = 0
while attempts[tries] != "secret":
    tries += 1
print("Correct after", tries + 1, "attempts")
```

```bash title="Terminal" verify="run"
python3 for_vs_while.py
```

```text title="Expected output"
for countdown: 3
for countdown: 2
for countdown: 1
while countdown: 3
while countdown: 2
while countdown: 1
Months needed: 3 Balance: 160
Correct after 3 attempts
```

The savings loop is a `while` loop because nobody knows in advance how many months are needed. If you forget `n -= 1`, the loop never ends: press Ctrl+C to stop it. A later lesson covers `while` in depth.

## Step 10: Avoid the common loop mistakes
Four mistakes cover most beginner loop bugs. Expecting `range(1, 5)` to include 5 loses the last value. Looping over `range(len(x))` and indexing is clumsy when `for item in x:` works. Removing items from a list while looping over that same list skips items, so loop over a copy. A missing colon or a missing indent is a syntax error. The last two checks use `compile()` so the script itself keeps running.

```python title="common_mistakes.py" file
print(list(range(1, 5)), list(range(1, 6)))

names = ["Ana", "Ben", "Cy"]

for i in range(len(names)):
    print(i, names[i])

for name in names:
    print(name)

nums = [1, 2, 2, 3]
for n in nums:
    if n == 2:
        nums.remove(n)
print("Changed while looping:", nums)

nums = [1, 2, 2, 3]
for n in nums[:]:
    if n == 2:
        nums.remove(n)
print("Looped over a copy:", nums)

total = 0
for n in [1, 2, 3]:
    total += n
    print("inside:", total)
print("after:", total)

try:
    compile("for x in [1, 2]\n    print(x)\n", "demo", "exec")
except SyntaxError:
    print("SyntaxError: missing colon")

try:
    compile("for x in [1, 2]:\nprint(x)\n", "demo", "exec")
except SyntaxError as error:
    print(type(error).__name__ + ": no indented body")
```

```bash title="Terminal" verify="run"
python3 common_mistakes.py
```

```text title="Expected output"

0 Ana
1 Ben
2 Cy
Ana
Ben
Cy
Changed while looping: [1, 2, 3]
Looped over a copy: [1, 3]
inside: 1
inside: 3
inside: 6
after: 6
SyntaxError: missing colon
IndentationError: no indented body
```

Removing from the list during the loop left one `2` behind, because the list shifted under the loop. The copy `nums[:]` is untouched while the real list changes. Write `for x in y:` and indent the body by 4 spaces.

## How it works
A `for` loop asks its iterable for the next value, assigns it to the loop variable, runs the indented body, and repeats until the iterable has no more values. `range()` does not build a list: it hands out integers one at a time, starting at `start`, stepping by `step`, and stopping before `stop`. The accumulator and maximum patterns work because a variable created before the loop keeps its value from one pass to the next.

Indentation defines the body: dedent to end the loop. In a nested loop, the inner loop starts again from its first value on every outer pass. After the loop the variable keeps the last value it received. Choose `for` when you know the items or the count, and `while` when you wait for a condition; a `while` loop must change something that makes its condition false.

## Common errors
### The last number is missing from a range
`range(1, 5)` stops before 5, so it gives 1, 2, 3, 4. The stop value is never included; write `range(1, 6)` to reach 5.

### `SyntaxError: expected ':'` or `IndentationError: expected an indented block`
The loop header must end with a colon and the body must be indented, normally by 4 spaces. Write `for x in y:` and indent every line of the body the same amount.

### Items are skipped when removing from a list inside its own loop
The list shifts while the loop is still counting positions. Loop over a copy with `for n in nums[:]:` or `for n in list(nums):`, or build a new list of the items you keep.

### `NameError` for the loop variable after an empty loop
The variable exists after a loop only if the loop ran at least once. Give it a starting value before the loop when you use it afterwards.

### The loop prints the total on every pass
`print(total)` is indented, so it belongs to the body. Dedent it to align with the `for` line so it runs once after the loop.

### A `while` loop never ends
The condition never becomes false, usually because the loop forgot to update its variable. Press Ctrl+C to stop the program, then add the missing update such as `n -= 1`.

## Recap
- `for item in iterable:` runs an indented body once per value, and `range(stop)`, `range(start, stop)`, and `range(start, stop, step)` never include the stop value.
- The accumulator and maximum patterns start with a value before the loop, update it inside, and use it after; nested loops run the inner loop fully for each outer pass.
- The loop variable survives the loop, `_` marks an unused value, and you choose `for` for known items or counts and `while` for a changing condition.

## Final practice: Loop Toolkit
The cheat sheet has no single longer program, so this one combines its ideas: an accumulator, the maximum pattern, `range()` with steps, loops over a string and a dictionary, `_`, a nested table, and the loop variable that survives the loop. Create `loop_toolkit.py`.

```python title="loop_toolkit.py" file
# Loop Toolkit - the cheat sheet's ideas in one program
scores = [72, 88, 95, 64, 81]

# Accumulator: total and average
total = 0
for score in scores:
    total += score
print("Total:", total)
print("Average:", total / len(scores))

# Find the maximum (start from the first item)
highest = scores[0]
for score in scores:
    if score > highest:
        highest = score
print("Highest:", highest)

# range() with a step and a negative step
print("Every third number:", list(range(0, 10, 3)))
for count in range(3, 0, -1):
    print("Countdown:", count)

# Iterate a string, a dict, and use _ when the value is not needed
vowels = 0
for letter in "introduction":
    if letter in "aeiou":
        vowels += 1
print("Vowels in 'introduction':", vowels)

stock = {"apples": 3, "pears": 5}
for fruit, amount in stock.items():
    print(fruit, "->", amount)

for _ in range(2):
    print("hi")

# Nested loops: a 3 x 3 multiplication table
for row in range(1, 4):
    line = ""
    for col in range(1, 4):
        line += f"{row * col:3}"
    print(line)

# The loop variable survives the loop
for student in ["Ana", "Ben", "Cy"]:
    pass
print("Last student:", student)
```
