## Why this matters
Python stores names in namespaces. Knowing whether a name belongs to a class, an instance, or a method explains shared defaults, instance overrides, and why changing one object sometimes affects another.

## What you will build
A `Course` class that demonstrates class attributes, instance attributes, lookup order, and deliberate shared configuration.

## Before you start
Create `namespaces.py`. Run it with `python3 namespaces.py` or `py -3 namespaces.py`.

## Step 1: Start with a class attribute
A name defined directly in the class body is available through instances. It is shared until an instance creates an attribute with the same name.

```python title="namespaces.py" file
class Course:
    language = "Python"


first = Course()
second = Course()
print(first.language, second.language)
print(Course.__dict__["language"])
```

```bash title="Terminal" verify="run"
python3 namespaces.py
```

```text title="Expected output"
Python Python
Python
```

## Step 2: Add instance attributes
Instance attributes normally belong in `__init__`. They are stored in the instance namespace and can differ between objects.

```python title="instance_namespace.py" file
class Course:
    language = "Python"

    def __init__(self, learner):
        self.learner = learner


first = Course("Mina")
second = Course("Omar")
print(first.__dict__)
print(second.__dict__)
print(first.language is second.language)
```

```bash title="Terminal" verify="run"
python3 instance_namespace.py
```

```text title="Expected output"
{'learner': 'Mina'}
{'learner': 'Omar'}
True
```

## Step 3: Observe lookup order
For `obj.name`, Python checks the instance first and then the class. Assigning `first.language` creates an instance attribute; it does not edit the class attribute.

```python title="lookup_order.py" file
class Course:
    language = "Python"


first = Course()
second = Course()
first.language = "JavaScript"
print(first.language)
print(second.language)
print(Course.language)
print(first.__dict__)
```

```bash title="Terminal" verify="run"
python3 lookup_order.py
```

```text title="Expected output"
JavaScript
Python
Python
{'language': 'JavaScript'}
```

## Step 4: Change shared configuration intentionally
Changing `Course.language` affects instances that do not have an overriding instance attribute. This is useful for shared constants, not per-learner data.

```python title="shared_config.py" file
class Course:
    language = "Python"


first = Course()
second = Course()
first.language = "JavaScript"
Course.language = "TypeScript"
print(first.language)
print(second.language)
```

```bash title="Terminal" verify="run"
python3 shared_config.py
```

```text title="Expected output"
JavaScript
TypeScript
```

## How it works
`Class.__dict__` exposes class-owned names and `obj.__dict__` exposes instance-owned names. Attribute lookup prefers an instance entry, then searches the class and its bases. A method is also a class namespace entry; accessing it through an instance binds the instance automatically.

## Common errors
### Using a class attribute for mutable per-object data
A list such as `members = []` in the class is shared. Create `self.members` in `__init__` instead.

### Expecting an instance assignment to update the class
`obj.value = 3` creates or replaces an instance entry.

### Editing `__dict__` casually
Use normal attributes and methods for application code; inspect `__dict__` to understand behavior.

## Recap
- Python separates class and instance namespaces.
- Instance attributes shadow class attributes with the same name.
- Shared class data should be intentional and usually immutable.
