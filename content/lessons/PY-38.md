## Why this matters
`nonlocal` updates an enclosing function variable, while `global` updates a module variable. Choosing the narrowest scope avoids hidden state.

## What you will build
A runnable set of examples about nonlocal versus global scopes.

## Before you start

## Step 1: Update an enclosing counter

```python title="py_38_1.py" file
def counter():
    value = 0
    def next_value():
        nonlocal value
        value += 1
        return value
    return next_value

next_value = counter()
print(next_value(), next_value())
```

```bash title="Terminal" verify="run"
python3 py_38_1.py
```

```text title="Expected output"

```

## Step 2: Use nonlocal safely

```python title="py_38_2.py" file
def make_score():
    score = 10
    def add(points):
        nonlocal score
        score += points
        return score
    return add

add = make_score()
print(add(5), add(2))
```

```bash title="Terminal" verify="run"
python3 py_38_2.py
```

```text title="Expected output"
15 17
```

## Step 3: Read and update a global

```python title="py_38_3.py" file
status = "ready"
def set_status(value):
    global status
    status = value

set_status("done")
print(status)
```

## Step 4: Compare the two scopes

```python title="py_38_4.py" file
def make_flag():
    flag = False
    def toggle():
        nonlocal flag
        flag = not flag
        return flag
    return toggle

toggle = make_flag()
print(toggle(), toggle())
```

```bash title="Terminal" verify="run"
python3 py_38_4.py
```

```text title="Expected output"
True False
```

## How it works
Use `nonlocal` for the nearest enclosing function scope.
Use `global` only when module-wide mutation is intentional.
A closure can encapsulate state without exposing a global.

## Common errors
### Repeating code instead of extracting a function
Give a helper one responsibility and return its result.

### Confusing a return value with printed output
Use `return` for callers and `print` only at the boundary.

### Hiding state or dependencies
Prefer explicit parameters and imports over surprising global behavior.
