## Why this matters
Every value in a Python program has a type, and the type decides what you can do with it, whether it can change, and how it behaves in a condition. Picking `Decimal` for money, a tuple for a fixed pair, or a set for unique tags removes whole classes of bugs before they start.

## What you will build
Small, standalone Python scripts that map the built-in types, check and convert them, work with numbers, strings, lists, tuples, and ranges, test truthiness and `None`, avoid alias and default-argument traps, and read type hints. You finish with one program that touches every type family.

## Before you start
Use Python 3.10 or newer and create each named file in a practice folder. Every example is independent. Run each file with `python3 filename.py` on macOS/Linux or `py -3 filename.py` in Windows PowerShell.

Python is dynamically typed (names have no fixed type) and strongly typed (values are never silently converted), and everything is an object with a type. This lesson builds on the numbers and operators from PY-02, the lists from PY-04, and the object and copy ideas from the earlier lessons in this track. Give your files the exact names shown, and never name a file after a standard-library module such as `numbers.py` or `decimal.py`.

## Step 1: Read the built-in type map
Each built-in type is either mutable (it can change in place) or immutable. The mutable ones are `list`, `dict`, `set`, and `bytearray`; `int`, `float`, `complex`, `bool`, `str`, `tuple`, `range`, `frozenset`, `bytes`, and `None` cannot change. `type(x).__name__` gives a type's name, and `bool` is a subclass of `int`.

```python title="type_map.py" file
values = [42, 3.14, 1 + 2j, True, "hi", [1, 2], (1, 2), range(0, 10, 2),
          {"a": 1}, {1, 2}, frozenset({1, 2}), b"hi", bytearray(b"hi"), None]

for value in values:
    print(f"{type(value).__name__:<10} {value!r}")

print([type(x).__name__ for x in (42, 3.14, 1 + 2j, "hi", [1], (1,), {1}, {"a": 1}, None)])

mutable = [list, dict, set, bytearray]
immutable = [int, float, str, tuple, bytes]
print([t.__name__ for t in mutable])
print([t.__name__ for t in immutable])
```

## Step 2: Check and convert types
`isinstance(value, type)` tests a type, and a tuple of types matches any of them. Constructors such as `int()`, `float()`, `str()`, `list()`, `tuple()`, `set()`, and `dict()` convert values explicitly. `ord()` and `chr()` map characters to codes, and `bin()`, `hex()`, and `oct()` write integers in other bases.

```python title="convert_types.py" file
print(isinstance(5, int))
print(isinstance(True, int))
print(isinstance(5, (int, float)))

print(int("42") + 1)
print(float("1e3"))
print(str(42) + "!")
print(list("abc"), tuple([1, 2]), set([1, 1, 2]))
print(dict([("a", 1)]))
print(ord("A"), chr(97))
print(bin(10), hex(255), oct(8))
print(int(float("3.7")), int(-3.7))
print("5" * 3)

try:
    int("3.7")
except ValueError as error:
    print("ValueError:", error)

try:
    "5" + 5
except TypeError as error:
    print("TypeError:", error)
```

## Step 3: Work with numbers
`/` is true division, `//` is floor division, `%` is the remainder, and `**` is the power. Floor division rounds toward negative infinity, `int` has no size limit, and underscores and base prefixes make literals readable. Floats are binary approximations, so compare them with `math.isclose()` and use `Decimal` for exact decimal arithmetic such as money.

```python title="number_types.py" file
import math
from decimal import Decimal

print(7 / 2, 7 // 2, 7 % 2, 2 ** 10)
print(divmod(17, 5))
print(-7 // 2)
print(2 ** 100)
print(1_000_000, 0b1010, 0o17, 0xFF)
print((2 + 3j) * (1 - 1j))
print(True + True)

print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
print(math.isclose(0.1 + 0.2, 0.3))
print(Decimal("0.1") + Decimal("0.2"))
print(round(2.5), round(3.5), round(3.14159, 2))
```

## Step 4: Treat strings as immutable text
Strings are immutable, so every method that seems to change one returns a new string and leaves the original alone. You can index, slice, search, split, join, and format them. An f-string accepts format specs after a colon, and a raw string keeps backslashes literal.

```python title="strings.py" file
s = "Python Rocks"
print(s[0], s[-1], s[0:6], s[::-1])
print(s.upper(), s.lower(), s.title())
print(s.replace("Rocks", "Rules"))
print(s)
print(s.split(" "))
print(", ".join(["a", "b", "c"]))
print(" padded ".strip())
print(s.find("R"), s.startswith("Py"), "thon" in s)

name, score = "Asha", 91.456
print(f"{name} scored {score:.1f}")
print(f"{1234567:,}")
print(f"{7:03d}|{'hi':>6}|{0.256:.1%}")
print(r"C:\new\table")

try:
    s[0] = "J"
except TypeError as error:
    print("TypeError:", error)
```

## Step 5: Change a list in place
A list is a mutable sequence. `append()`, `extend()`, `insert()`, `remove()`, and `sort()` change it in place; `remove()` deletes the first item equal to a value, and `pop()` removes and returns the last item. `sorted()` returns a new list and leaves the original alone.

```python title="list_ops.py" file
nums = [5, 2, 8]
nums.append(1)
nums.extend([9, 7])
nums.insert(0, 100)
nums.remove(2)
print(nums.pop())
print(nums)
print(sorted(nums), nums[::2], nums[-2:])
print(nums)

nums.sort(reverse=True)
print(nums)
print([n * n for n in range(5) if n % 2 == 0])
```

## Step 6: Use tuples and ranges
A tuple is an immutable sequence. The comma makes the tuple, so `(42)` is an `int` and `(42,)` is a tuple. Starred unpacking collects the remaining items into a list. `range(start, stop, step)` is an immutable sequence of integers that excludes `stop`, and it computes its items instead of storing them.

```python title="tuple_range.py" file
t = (1, 2, 3)
print(type((42)).__name__, type((42,)).__name__)

first, *rest = t
print(first, rest)

try:
    t[0] = 9
except TypeError as error:
    print("TypeError:", error)

print(list(range(2, 11, 3)))
r = range(0, 10, 2)
print(len(r), r[1], 4 in r, r)
print(tuple([1, 2]) == (1, 2))
```

## Step 7: Test truthiness and None
Every object can be used in a condition. The falsy values are `None`, `False`, zero of any numeric type, and empty containers or text: `""`, `[]`, `()`, `{}`, `set()`, and `range(0)`. Everything else is truthy, including `"0"`, `"False"`, `[0]`, and a single space. Test for `None` with `is`, not `==`.

```python title="truthiness.py" file
probes = (0, 0.0, "", [], {}, set(), None, "0", [0], " ")
print([bool(x) for x in probes])
print(bool("False"))

x = None
print(x is None)

cart = []
if not cart:
    print("cart is empty")

count = 0
print(count is None, count == None, count is not None)
```

`if not cart:` is the usual way to ask whether a container is empty. Zero is falsy but it is not `None`, so `if count:` and `if count is not None:` mean different things when `0` is a valid value.

## Step 8: Separate identity from equality and copy safely
`b = a` makes two names for one object, so changing a mutable object through either name changes both. `a.copy()` creates an independent shallow copy. `is` asks whether two names refer to the same object, and `==` asks whether the values are equal. A shallow copy copies only the outer container, so inner lists are still shared.

```python title="copies.py" file
a = [1, 2]
b = a
b.append(3)
print(a)

c = a.copy()
c.append(4)
print(a, c)
print(a is b, a is c, a == c)

nested = [[1], [2]]
shallow = nested.copy()
shallow[0].append(99)
print(nested, shallow)
```

```

True False False
[[1, 99], [2]] [[1, 99], [2]]
```

`a == c` is `False` here because `c` gained an item, while `a is b` is `True` because they are the same list. For nested data, use `copy.deepcopy()` from the standard library when the inner lists must also be independent.

## Step 9: Never use a mutable default argument
A default value is created once, when the function is defined, not on every call. A default `[]`, `{}`, or `set()` is therefore shared by all calls that omit that argument, and results leak from one call into the next. Use `None` as the default and build a fresh object inside the function.

```python title="default_args.py" file
def add_item(item, bucket=[]):
    bucket.append(item)
    return bucket


print(add_item(1), add_item(2))


def add_item_fixed(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket


print(add_item_fixed(1), add_item_fixed(2))
```

The first line shows `[1, 2]` twice because both calls returned the same shared list, which held both items by the time `print` ran. The fixed version prints `[1] [2]` because each call builds its own list.

## Step 10: Add type hints, and know they are not enforced
Hints such as `n: int` and `-> int` document what a function expects and returns. Python does not check them at run time, so a wrong argument still runs. Tools such as `mypy` or `pyright` read the hints and report violations before you run the code. Container hints like `list[str]` and unions like `int | None` work in Python 3.10 and newer.

```python title="type_hints.py" file
def double(n: int) -> int:
    return n * 2


print(double(4))
print(double("ab"))

names: list[str] = ["a", "b"]
scores: dict[str, int | None] = {"a": 1, "b": None}
print(names, scores)
print(double.__annotations__)
```

## Step 11: Choose the right type
Match the type to the job. Use a set to drop duplicates, a tuple for a fixed value that must be a dictionary key, a `dict` for labelled fields, a `Decimal` for exact money, and a `frozenset` for an unchangeable set. Only hashable (immutable) objects can be dictionary keys or set members, so a list is rejected.

```python title="choose_type.py" file
from decimal import Decimal

tags = ["python", "data", "python", "types", "data"]
unique_tags = sorted(set(tags))
print(unique_tags)

point = (3, 4)
grid = {point: "start"}
print(grid[(3, 4)])

try:
    {[3, 4]: "start"}
except TypeError as error:
    print("TypeError:", error)

price = Decimal("0.10")
print(price * 3)
print(0.1 * 3)

user = {"name": "Asha", "age": 30}
user["age"] += 1
print(user)

frozen = frozenset({1, 2})
print(frozen | {3} == {1, 2, 3}, type(frozen | {3}).__name__)
```

## How it works
Python names refer to objects, and each object carries its type. Immutable objects (numbers, strings, tuples, `bytes`, `frozenset`, `None`) can never change, so operations on them create new objects. Mutable objects (lists, dictionaries, sets, `bytearray`) change in place, which is why aliases, shallow copies, and shared default arguments can surprise you.

Typing is strong: Python converts only when you ask, using constructors such as `int()` and `str()`. Conditions use truthiness, so zero, empty containers, and `None` are false and everything else is true. Type hints describe intent for people and checkers; the interpreter ignores them.

## Common errors
### `ValueError: invalid literal for int() with base 10: '3.7'`
`int()` cannot parse a decimal string. Convert with `int(float("3.7"))`, which truncates toward zero, or use `round()` if you want the nearest integer.

### `TypeError: can only concatenate str (not "int") to str`
Python never converts silently. Convert one side yourself with `str(5)` or `int("5")`, or use an f-string such as `f"{name}: {count}"`.

### `TypeError: 'str' object does not support item assignment`
Strings and tuples are immutable. Build a new value instead, for example `"J" + s[1:]`, or convert a tuple to a list, change it, and convert it back.

### `TypeError: unhashable type: 'list'`
Dictionary keys and set members must be hashable. Use a tuple (or a `frozenset`) in place of a list or a set.

### Results from one call show up in the next call
A mutable default argument such as `bucket=[]` is shared between calls. Use `bucket=None` and create the list inside the function.

### `0.1 + 0.2 == 0.3` is `False`
Floats are binary approximations. Compare with `math.isclose()`, or use `Decimal` built from strings for exact decimal values.

## Recap
- Types are either mutable (`list`, `dict`, `set`, `bytearray`) or immutable (numbers, `str`, `tuple`, `bytes`, `frozenset`, `None`); Python is strongly typed, so you convert explicitly with `int()`, `str()`, `list()`, and the other constructors.
- Use `Decimal` for exact money, `math.isclose()` for floats, `is None` for `None`, and remember that empty containers, zero, and `None` are falsy.
- `b = a` is an alias and `copy()` is shallow, mutable defaults are shared between calls, and type hints are never enforced at run time.

## Final practice: Data Type Toolkit
The cheat sheet is a reference rather than a single program, so this program gathers its ideas into one script. Create `data_type_toolkit.py`; each printed line is numbered after the cheat-sheet section it exercises.

```python title="data_type_toolkit.py" file
# Data Type Toolkit - one program that uses every type family
from decimal import Decimal
import math


def describe(value):
    kind = type(value).__name__
    mutable = isinstance(value, (list, dict, set, bytearray))
    truthy = "truthy" if value else "falsy"
    return f"{kind:<9} mutable={mutable!s:<5} {truthy}"


def add_item(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket


def double(n: int) -> int:
    return n * 2


# 1. Type map
for sample in (42, 3.14, 1 + 2j, True, "hi", [1], (1,), {"a": 1}, {1}, None):
    print("1.", describe(sample))

# 2. Checking and converting
print("2.", isinstance(True, int), int("42") + 1, float("1e3"), list("abc"))

# 3. Numbers
print("3.", divmod(17, 5), -7 // 2, 2 ** 100)
print("3.", 0.1 + 0.2 == 0.3, math.isclose(0.1 + 0.2, 0.3), Decimal("0.1") + Decimal("0.2"))
print("3.", round(2.5), round(3.5), round(3.14159, 2))

# 4. Strings
s = "Python Rocks"
print("4.", s[::-1], s.replace("Rocks", "Rules"), f"{1234567:,}", f"{0.256:.1%}")

# 5. list, tuple and range
nums = [5, 2, 8]
nums.append(1)
nums.extend([9, 7])
nums.insert(0, 100)
nums.remove(2)
last = nums.pop()
print("5.", last, nums, sorted(nums))
first, *rest = (1, 2, 3)
print("5.", first, rest, list(range(2, 11, 3)), [n * n for n in range(5) if n % 2 == 0])

# 6. Truthiness and None
print("6.", [bool(x) for x in (0, "", [], None, "0", [0])])

# 7. Aliases, copies and defaults
a = [1, 2]
b = a
b.append(3)
c = a.copy()
c.append(4)
print("7.", a, c, a is b, a is c, a == c)
print("7.", add_item(1), add_item(2))

# 8. Type hints are not enforced
print("8.", double(4), double("ab"))
```
