## Why this matters
Attribute shadowing occurs when a more specific attribute hides one with the same name on a class or base class. Understanding it prevents bugs caused by accidental overrides and helps you design clear object APIs.

## What you will build
A `Report` class that demonstrates shadowing, deletion, and safe inspection of where an attribute comes from.

## Before you start
Create `shadowing.py` and run it with Python 3.10 or newer.

## Step 1: Shadow a class attribute
An instance assignment creates a more specific value.

```python title="shadowing.py" file
class Report:
    status = "draft"


report = Report()
print(report.status)
report.status = "review"
print(report.status)
print(Report.status)
```

```bash title="Terminal" verify="run"
python3 shadowing.py
```

```text title="Expected output"
draft
review
draft
```

## Step 2: Remove the shadow
Deleting the instance attribute reveals the class attribute again.

```python title="remove_shadow.py" file
class Report:
    status = "draft"


report = Report()
report.status = "review"
del report.status
print(report.status)
```

```bash title="Terminal" verify="run"
python3 remove_shadow.py
```

```text title="Expected output"
draft
```

## Step 3: Shadow a method carefully
Methods are attributes too. Replacing a method on one object can make that object behave differently from every other instance.

```python title="shadow_method.py" file
class Report:
    def label(self):
        return "standard"


report = Report()
print(report.label())
report.label = lambda: "custom"
print(report.label())
print(Report().label())
```

```bash title="Terminal" verify="run"
python3 shadow_method.py
```

```text title="Expected output"
standard
custom
standard
```

## Step 4: Inspect the source of a value
The instance dictionary shows whether a value is shadowing a class member.

```python title="inspect_shadow.py" file
class Report:
    status = "draft"


report = Report()
print("status" in vars(report))
report.status = "review"
print("status" in vars(report))
print(vars(report), Report.__dict__["status"])
```

```bash title="Terminal" verify="run"
python3 inspect_shadow.py
```

```text title="Expected output"
False
True
{'status': 'review'} draft
```

## How it works
Attribute lookup chooses the most specific applicable definition. An instance entry normally wins over a non-data class attribute, while a property or other data descriptor can take precedence. `del obj.name` removes only the instance entry.

## Common errors
### Changing the class when only one object should change
Use `obj.name = value`; assign `Class.name` only for a deliberate shared change.

### Calling a shadowed method without checking its type
An instance attribute can replace a method with a non-callable value. Keep public names consistent.

### Using shadowing as the main configuration system
Prefer explicit constructor arguments or properties when an override is part of the design.
