## Step 1: Log a function call at one boundary

This example focuses on how to log a function call at one boundary.

```python title="build_a_logger_with_a_decora_1.py" file
from functools import wraps

def logged(function):
    @wraps(function)
    def wrapper(*args, **kwargs):
        print("LOG", function.__name__, args)
        return function(*args, **kwargs)
    return wrapper

@logged
def greet(name):
    return f"Hello, {name}!"

print(greet("Ada"))
```

```bash title="Terminal" verify="run"
python3 build_a_logger_with_a_decora_1.py
```

```text title="Expected output"
LOG greet ('Ada',)
Hello, Ada!
```

## How it works
The syntax and control flow determine whether work happens eagerly or on demand. Keep transformations readable, consume iterators deliberately, and make wrapper behavior explicit.

## Common errors
### Building the wrong collection
Choose the collection type from the required output: lists preserve order, sets enforce uniqueness, dictionaries name values, and generators defer work.

### Consuming a generator twice
A generator is an iterator and is normally exhausted after one pass. Create a new generator or materialize intentionally when repeated access is required.

### Hiding behavior in a wrapper
Use `functools.wraps`, preserve arguments, and raise a clear exception when a decorator rejects a call.
