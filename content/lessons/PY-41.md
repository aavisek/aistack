## Why this matters
Lambdas are concise function expressions, while purity describes whether a function depends on or changes outside state. Both choices affect readability and testing.

## What you will build
A runnable set of examples about lambdas, pure versus impure functions.

## Before you start
Create each named script in a Python 3.10+ environment and run the commands below.

## Step 1: Sort with a lambda

```python title="py_41_1.py" file
items = [("b", 2), ("a", 3)]
print(sorted(items, key=lambda pair: pair[0]))
```

## Step 3: Identify an impure function

```python title="py_41_3.py" file
total = 0
def add(value):
    global total
    total += value
    return total

print(add(2), add(3))
```

```bash title="Terminal" verify="run"
python3 py_41_3.py
```

```text title="Expected output"
2 5
```

## Step 4: Choose the clearest form

```python title="py_41_4.py" file
def format_name(first, last):
    return f"{last}, {first}"

print(format_name("Ada", "Lovelace"))
```

```bash title="Terminal" verify="run"
python3 py_41_4.py
```

```text title="Expected output"
Lovelace, Ada
```

## How it works
Use a lambda for a short expression, not a multi-step algorithm.
Pure functions are easy to repeat and test.
Mutation is sometimes useful, but make it visible in the interface.

## Common errors
### Repeating code instead of extracting a function
Give a helper one responsibility and return its result.

### Confusing a return value with printed output
Use `return` for callers and `print` only at the boundary.

### Hiding state or dependencies
Prefer explicit parameters and imports over surprising global behavior.
